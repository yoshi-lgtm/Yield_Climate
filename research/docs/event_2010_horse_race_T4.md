## 1. 設計

T4 の本体は horse race である（頑健性ではない）。$\delta$ の識別仮定は

> **heat 曝露を条件づけたとき、`consol30` と相関する他の市町村特性が高温被害を修飾しない**

で、単一事象設計では「複数事象で頑健」という逃げ道がない。T15 で $\delta_{2010}$ が t 2.07 → 0.98 になった原因が 2010年内の $heat\cdot c$ と $c$ の共線だったので、次の問いは

> **`consol30` 固有の何かが効いているのか、規模や地理の代理になっているだけか**

である。

### 1.1 競合変数

すべて時間不変。市町村断面で標準化した（`consol30` だけは既存文書と数値を揃えるため生のまま）。

| 変数 | 内容 | `consol30` との相関 |
|---|---|---|
| `pipe` | パイプライン率（2010年センサス）。**水管理の直接の代理** | 0.201 |
| `paddy_fix` | 水田率（時間不変版） | 0.243 |
| $\log$`den` | 0.2ha 以上の田面積の対数。**経営規模の代理** | 0.137 |
| `lat` | 市町村重心の緯度（`results/city_centroids.csv`） | **0.009** |
| `lon` | 市町村重心の経度 | **0.060** |

**標高・海岸距離のデータがないので、緯度・経度をその粗い代理として使う。** 相関が低いので horse race は退化しない。

### 1.2 推定式

$$\ln y_{it} = \alpha_i + \tau_t + \sum_{t\neq 2000}\mathbb{1}[t]c_i + \sum_{t\neq 2000}\mathbb{1}[t]W_{ki} + \sum_t \mathbb{1}[t]\big(\beta_t heat_{it} + \delta_t heat_{it}c_i + \gamma_{kt} heat_{it}W_{ki}\big) + \gamma X_{it} + \varepsilon_{it}$$

競合は**年飽和で入れる**。水準項も年別に入れる（T15 と同じ扱い）。SE は市町村クラスター。

### 2.2 (a) は頑健に null

$\delta_{2010}$ は 9通りすべてで **+0.0018 〜 +0.0043、t = 0.68 〜 1.96**。競合を入れると点推定はむしろ上がるが、t は最大でも 1.95〜1.96 で 5% に届かない。

**T12（IM で t = 0.69）・T15（飽和で t = 0.98）と整合し、(a) を informative null として報告する方針は T4 でも変わらない。** 論文が $\delta_{2010}$ の有意性に依存しない構成になっていることが、ここでも効いている。

### 2.3 (c) の低下は検出力の損失ではない — 点推定が揃っている

これが T4 でいちばん重要な数値である。

| | base | + `lat`+`lon`（年飽和） |
|---|---|---|
| $\mathrm{sd}(\hat\delta_t)$ | **0.00799** | **0.00341**（**-57%**） |
| 平均 SE | 0.00368 | 0.00372（**ほぼ不変**） |
| $\mathrm{sd}/\overline{SE}$ | **2.17** | **0.92** |

**Wald 統計量が落ちたのは SE が膨らんだからではない。$\hat\delta_t$ の散らばり自体が半分以下になり、標本誤差から期待される大きさ（比 ≈ 1）まで縮んでいる。**

農学・規模の競合（`pipe`・`paddy_fix`・$\log$`den`）では比が 1.87〜2.23 と base とほぼ同じで、散らばりは縮まない。**地理だけが効く。**

### 2.4 したがって

> **$\delta_t$ の年次異質性に見えていたものの大半は、年固有の空間的な熱感応度勾配である。** `consol30` はそれを代理していた。

`heat × lon` の2010年交差項は +0.0065、**t = 4.1〜4.4** で全スペックで頑健に生き残る（`heat × lat` は -0.0017〜-0.0053、t -1.35〜-2.68）。**2010年の高温被害には強い東西勾配があった。**

**未解明な点を正直に書く。** `consol30` と `lat`・`lon` の単純相関は **0.009・0.060** とほぼゼロである。それにもかかわらず年固有の地理勾配が $\hat\delta_t$ の散らばりを吸収するのは、無条件の相関ではなく**年内の heat 曝露パターンを条件づけたときの関係**が効いているためと考えられるが、本稿では機序を特定していない。


### 2.5 標高では説明できない（2026年10月23日に追加）

§2.4 で「経度が何の代理かは特定していない」と書いた。第一候補は**標高**だった — 関東は西が山地・東が平野で、気温は逓減率で標高に従う。国土数値情報 G04-a「標高・傾斜度3次メッシュデータ」（平成11年、JGD2000）を関東11枚ぶん取得し、**気象集計と同一の田面積加重 $W$** で市町村に集計した（`Data_cleaning/13build_city_elevation.py`、メッシュ結合率 **98.2%**）。

メッシュ農業気象データのグリッドは標準地域メッシュ（3次＝約1km）そのもので、ラスタの CRS も **EPSG:4612（JGD2000）**なので標高側と測地系が一致する。したがってピクセル中心の経緯度から3次メッシュコードを算術で決めて結合できる。海側メッシュは `unknown` が入るので除外した（58,200行中 4,431件）。

| | 田面積加重 |
|---|---|
| 平均標高 | 中央値 **37.0 m**、平均 94.3 m、最大 1,137.7 m |
| 平均傾斜 | 中央値 0.95°、平均 1.98° |
| 起伏（最高−最低） | 中央値 25.5 m、平均 52.3 m |
| 単純平均との差 | **-8.5 m**（田は市町村平均より低い。整合的） |

**標高は経度と -0.497 で相関する。** 仮説の前提は満たされている。

**根拠は3つとも同じ向きを指している。**

1. **標高単独では $\delta_t$ の散らばりがまったく縮まない。** $\mathrm{sd}/\overline{SE}$ は base の 2.17 に対して **2.24**。緯度・経度が 0.92〜0.98 まで落とすのと対照的である。$\chi^2$ も 81.9 → 72.2 で、`paddy_fix`（72.3）・$\log$`den`（66.6）といった農学・規模の競合と同程度しか動かない
2. **経度と同時に入れると標高の2010年交差項は消える。** 単独では -0.00722（t **-3.64**）だが、`lon` を入れると **-0.00099（t -0.46）**、`lat`+`lon` を入れると **-0.00001（t -0.00）**。逆に `lon` は +0.00601（t **+3.40**）・+0.00534（t **+3.23**）で生き残る
3. **`lat`+`lon` に標高を足しても $\chi^2$ はほとんど動かない**（29.9 → 26.4）

> **標高単独の見かけの効果は、経度との相関 -0.497 を通じたものである。経度は標高の代理ではない。**

#### 不安定なスペックの注記

`elev`+`slope` を同時に入れると係数が暴れる（`elev` -0.02582（t -5.50）、`slope` +0.01312（t +5.09））。両者の相関が **0.767**（`slope` と `relief` に至っては 0.995）なので多重共線によるもので、**解釈してはならない**。競合8本すべてを入れた版（$\chi^2$ = 69.2）も同じ理由で不安定である。**解釈可能なのは上表の組み合わせだけ。**

#### では経度は何の代理か（暫定）

パネル内で作れる市町村の恒常的な気候特性を同じ形（時間不変・標準化・年飽和）で当てた。

| 競合 | 経度との相関 | 2010年交差項 | t | $\chi^2(23)$ |
|---|---|---|---|---|
| **`tmin_fix`**（登熟期の平均最低気温） | **+0.583** | +0.00911 | **+4.50** | 70.7 |
| **`tmax_fix`**（同 平均最高気温） | +0.493 | +0.00881 | **+4.40** | 72.5 |
| **`apcp_fix`**（同 降水量） | **-0.680** | -0.00577 | **-3.41** | 62.7 |
| `night_fix`（`obs_NIGHT26` の平均） | +0.061 | -0.00006 | **-0.10** | 54.8 |
| `elev` | -0.479 | -0.00722 | -3.64 | 72.2 |

`lon` と同時に入れると `tmin_fix` t = 3.16 / `lon` t = 2.65 で**両方が残り、どちらも相手を吸収しない**。

**係数の符号は解釈できる。** `tmin_fix` の2010年交差項が**正**＝**恒常的に暖かい市町村ほど、HD35 1日あたりの被害が小さかった**。これは Burke & Emerick (2016) が論じる断面の適応シグネチャそのものである（暖地は高温に適した品種・慣行を持つ）。**夜間高温（`night_fix`）はまったく効かない**ので、白未熟粒の経路ではない。

ただし `tmin_fix` も `lon` を完全には吸収しない。**経度の正体は特定できていない。** 残る候補は海岸距離（海洋性の緩和）で、本稿では測っていない。


### 2.6 海岸距離は効く（2026年10月23日に追加）

標高が否定されたので、残る第一候補の**海岸距離**を測った。国土数値情報 C23「海岸線」（平成18年、JGD2000）の臨海4都県（茨城08・千葉12・東京13・神奈川14。群馬・栃木・埼玉は内陸）を読み、**東京の小笠原・伊豆諸島を関東 bbox でクリップ**して（3,259本 → 73本）、計 **1,732本・総延長 1,471km** を得た。

田面積加重の経路は §2.5 と同一で、**ピクセルごとに最寄り海岸線までの距離**を平面直角座標系 IX 系（EPSG:2451、JGD2000）で測り、田面積で加重平均した（`Data_cleaning/14build_city_coastdist.py`）。田面積加重の海岸距離は中央値 **29.8 km**、最大 146.3 km。

**`coast`+`elev` が全スペック中で最良である**（$\chi^2$ = 24.1、p = 0.400、比 **0.70**）。この組み合わせには経度が入っていないにもかかわらず (c) は決定的に棄却されない。しかも**この式の中で有意なのは `coast` だけ**（2010年交差項 -0.00539、t **-2.46**）で、**`elev` は t = -0.65 で効かない**。

> **2010年の高温被害の地理勾配は、地形（標高）ではなく海洋性（海岸距離）である。**

符号も解釈できる。`coast` の2010年交差項は**負**＝**海から遠いほど HD35 1日あたりの被害が大きい**。内陸ほど日較差が大きく夜温も下がりにくい、という海洋性の緩和と整合する。

| + `coast`+`lat`+`lon` | -0.00314（t -1.12） | +0.00412（t **+2.65**） |
| + `coast`+`elev`+`lat`+`lon` | -0.00201（t -0.63） | +0.00446（t **+2.94**） |

経度と同時に入れると `coast` は弱まり、`lon` が残る。**しかしこれを「正体は経度であって海岸距離ではない」と読んではならない。** 相関 -0.594 の2つの代理変数の総当たりは、**測定誤差の小さい方が勝つ**だけである。経度は誤差なしで測れるのに対し、海岸距離は海岸線データの版・bbox・投影法・最寄り定義という構築上の選択を含む。

**言えることは3つに限られる。**

1. **標高は否定された**（`lon` にも `coast` にも負ける）
2. **海岸距離は単独で最も強く、符号も物理的に解釈できる**。説明力の順は `coast` ≈ `lon` > `lat` $\gg$ `elev`
3. **東西の勾配は実在し頑健である**。どの代理を使っても (c) は棄却されなくなる（$\chi^2$ = 24〜35）

したがって**本文では「海洋性の緩和」として `coast` を使い、経度は頑健性に回す**のが妥当である。物理的な機序を名指しできる方が、座標そのものより説得力がある。

#### $\delta_{2010}$ について

地理勾配を正しく統制すると $\delta_{2010}$ は **+0.0043〜+0.0046（t = 1.93〜2.11）**まで上がり、`+ coast` 単独では **t = 2.11** と5%をかすめる。ただし §2.1 のとおり他の地理スペックでは 1.45〜1.64 に留まり、**頑健な有意性ではない**。(a) を informative null として報告する方針は変えない。

## 3. 機序：`consol30`（区画規模）対 `pipe`（水管理）

理論は「整備 → 用排水インフラ → 掛け流し・深水かんがい → 水温低下 → 高温害緩和」である。しかし `consol30` が測っているのは**区画の大きさ**で、水管理なら `pipe` の方が直接的である。

| 年 | $\delta$(`consol30`) | t | $\gamma$(`pipe`) | t |
|---|---|---|---|---|
| 2007 | +0.00422 | **2.36** | +0.00027 | 0.45 |
| **2010** | +0.00176 | **0.68** | +0.00070 | **0.67** |
| 2012 | +0.00295 | **2.78** | -0.00066 | -1.77 |
| 2013 | +0.00211 | 1.12 | -0.00065 | -0.94 |
| 2015 | -0.00828 | **-2.50** | -0.00376 | **-2.26** |
| 2018 | +0.00202 | 1.52 | -0.00056 | -1.17 |
| 2023 | +0.00134 | 1.89 | -0.00018 | -0.71 |

24年のうち \|t\| > 1.96 は **`consol30` が5年、`pipe` が4年**。

**水温の物語は支持されない。** 2010年はどちらも null（t = 0.68 対 0.67）で区別がつかず、`pipe` が有意になる年（2015年など）は**符号が負**で緩和の逆である。

> **`consol30` で効いて `pipe` で効かない、という切り分け自体が立たない。2010年についてはどちらも効いていない。**

したがって「大区画 → 水管理 → 水温低下」という経路を本文で主張することはできない。`consol30` が何を代理しているかは特定できておらず、**§2.4 の地理勾配の結果と合わせると「整備率の緩和効果」という読み自体が支えられていない。**

## 5. 論文への含意

### 5.1 主結果（G0・$\omega_t$ 分解）は影響を受けない

$\hat\delta=\sum_t\omega_t\hat\delta_t$ は**恒等式**で、DGP の仮定も検定も要さない。「プール推定値がこの重みでこう組成されている」という言明は T4 の結果と無関係に成り立つ。

**`estimand_window_policy_2026-10.md` §1.1 と §1.7 で「分解が主、検定は補強。検定が棄却したからプールが悪いと書くと、棄却しなければ崩れる論文になる」と書いた判断が、実際に効いた。** 補強材の方が崩れたが、論文の骨格は立っている。

### 5.2 書き換えが要る記述

| 文書 | 現在の記述 | 要修正 |
|---|---|---|
| `vcov_inference_T12.md` §0・§8 | 「**(c) 決定的に棄却**。$\chi^2(23)$ = 98.4、p = 2.7e-11」 | **「年固有の空間勾配を統制しない場合は」という条件を付ける。** 統制すると 29.9（p = 0.15）で棄却されない |
| `goals_and_todo.md` §3.7 | 同上 | 同上 |
| `research_portfolio_summary.md` §1 | 「被害関数が非定常」「$\delta_t$ の異質性」 | **異質性の大半が空間×年の勾配だった**ことを反映 |

### 5.3 むしろ主張は精密になる（ただし別の主張になる）

| | 旧 | 新 |
|---|---|---|
| $\delta_t$ の異質性 | 緩和効果が本当に年で違う | **大半は年固有の空間的熱感応度勾配**。`consol30` がそれを代理していた |
| プール推定量の問題 | 異質な $\delta_t$ を平均している | **モデルに入っていない交互作用（空間×年）を $\delta$ に押し込んでいる。** 汚染項の物語と同じ型で、より強い |

**これは「脱落交互作用」の話なので、$\beta_t$ 由来の汚染項（T11・T12）と同じ系統の現象である。** 論文の筋としてはむしろ一貫する。ただし**「$\delta_t$ は異質だ」から「$\delta_t$ の異質性は見かけで、別の脱落項の反映だ」への書き換え**であり、スピンではなく変更として扱う。

### 5.4 本番スペックをどうするか（未決）

地理の年飽和を本番に入れると、$\omega_t$・$\delta_t$・プール $\hat\delta$ がすべて変わる。**$\omega$ 分解を地理飽和スペックで再計算する必要がある**（恒等式自体はどのスペックでも成立する）。

選択肢：

- **(i) 地理飽和を本番にする。** 最も保守的。(c) は棄却されなくなるので、論文は分解のみに立つ
- **(ii) T15 飽和を本番、地理飽和を頑健性。** (c) の棄却を報告しつつ、「年固有の空間勾配を許すと棄却されない」を**本文に明記**する
- **(iii) 両方を並べる。** 「何を統制すると何が消えるか」を結果として提示する

**(iii) が論文の立場（estimand の特定）と最も整合する。** 「$\delta_t$ の異質性がどの交互作用に帰属するか」自体が、プール推定量が何を拾っているかの記述になる。
