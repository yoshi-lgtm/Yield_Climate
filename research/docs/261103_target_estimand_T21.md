## 1. なぜこれが必要だったか

T11 以来、分解の報告は次の形だった。

- 汚染項はプール値の **28.2%**（T18）
- 2010年の寄与は **87.2%**、2015年は **-27.2%**（T18）
- 負の $\omega_t$ が **8年**（T18）

これらはすべて**プール値 $\hat\delta_{\text{pool}}$ を分母にしている**。したがって答えているのは「**報告されてきた単一の数値は何で出来ているか**」であって、「**その数値は、知りたかった量からどれだけ離れているか**」ではない。

後者を答えないままでは、次の二つが言えない。

1. **離れ方の符号と大きさ。** 分母が内生的に決まっているので、構成比が大きいことは距離が大きいことを意味しない。実際 (C) に対しては汚染がギャップの 90.3% を占めるが、**ギャップ自体は有意でない**。「汚染 28.2%」からこれは導けない。
2. **離れ方の統計的有意性。** 構成比に SE は付いていない。ギャップには付く。

**outline §3.3 ④で「汚染項という量が特定できる」ことを estimand で語る利点に挙げている。** その利点を最後まで使うなら、target を書いて距離を測るところまで行くのが筋である。本稿はそこを埋める。

## 2. 設定

### 2.1 恒等式（T18 §2 の再掲）

$$\hat\delta_{\text{pool}} = \underbrace{\sum_t w_{D,t}\hat\delta_t}_{\text{主項}} + \underbrace{\sum_t w_{h,t}\hat\beta_t}_{\text{汚染1}} + \underbrace{\sum_t w_{G,t}\hat\gamma_t}_{\text{汚染2}} + \underbrace{\sum_t w_{F,t}\hat\eta_t}_{\text{汚染3}},\qquad w_{A,t}=\frac{\sum_i \tilde D_{it}A_{it}}{\sum_s\sum_i \tilde D_{is}^2}$$

本稿の実行でも $\sum_t w_{D,t} = 1.0000000000$、恒等式の誤差 **-2.93e-14**。T18・T20 と一致する。

### 2.2 target estimand とギャップの分解

target を $\theta = \sum_t a_t\delta_t$（$\sum_t a_t = 1$）の形に限る。すると

$$\hat\delta_{\text{pool}} - \hat\theta = \underbrace{\sum_t (w_{D,t} - a_t)\,\hat\delta_t}_{\text{重みのずれ}} \;+\; \underbrace{\sum_t w_{h,t}\hat\beta_t + \sum_t w_{G,t}\hat\gamma_t + \sum_t w_{F,t}\hat\eta_t}_{\text{汚染（$a$ に依存しない）}}$$

**汚染項は $a$ を含まない。** したがって**どの target を選んでも汚染の寄与は同じ +0.000342 で動かない**。target を変えて動くのは重みのずれだけである。これは報告上とても扱いやすい：**「target の選択に依存する部分」と「しない部分」が代数的に分離している**。

### 2.3 推論

$a_t$・$w_{A,t}$ はどちらも $X$ に条件付けば**定数**（回帰子行列だけの関数。outline §3.2 の最終項目）。よって $\hat\theta$、$\hat\delta_{\text{pool}} - \hat\theta$、重みのずれの3つはいずれも年飽和式の係数ベクトル $\hat b$ の**固定ウェイト線形結合** $\mathbf{a}'\hat b$ であり、

$$\widehat{\mathrm{Var}}(\mathbf{a}'\hat b) = \mathbf{a}'\,\widehat{\mathrm{Var}}(\hat b)\,\mathbf{a}$$

で SE が出る。**同じ $\widehat{\mathrm{Var}}(\hat b)$ を使うので、target・主項・汚染・プール値・ギャップがすべて同一の VCV の上で整合的に並ぶ。** クラスター（市町村）と Conley 50km の二本を出す。

**IM は構造的に使えない。** target はいずれも $\delta_t$ の線形結合なので、IM に乗せるには都県別の年飽和が必要になる。それは神奈川で41係数が落ちて推定不能（T19 §1.1）、年を4期に粗視化すれば通るが粗視化そのものが汚染項を壊す（28.2% → 5.0%、T20 §4）。**(c) を塞ぐのと同じ $G=6$ の階数制約である。**

### 2.4 target の選び方（post-selection を避ける）

統制の選択で課した規律（$\chi^2$ でスペックを選ぶのは post-selection、T18 §1）を **target にも課す**。

| target | 定義 | 何を見て決めたか |
|---|---|---|
| **(A) 等重み平均** | $a_t = 1/24$ | **何も見ていない。** 推定量にもデータにも依存しない |
| **(B) 曝露加重平均** | $a_t = \bar h_t/\sum_s \bar h_s$ | **曝露分布だけ。** 左辺（収量）を一切見ない |
| **(C) 高曝露5年の平均** | 年平均 HD35 上位5年に $1/5$ | **曝露分布だけ。** 同上 |
| **(D) $\delta_{2010}$** | 2010年に 1 | **事前に決めてある設計年**（T4・T15・T17・T20 がすべて 2010年） |
| (E) 中位曝露年（参考） | 中位の年に 1 | 曝露分布だけ。**(B)(C) の中間を見るためで、主結果には置かない** |

**どれも $\hat\delta_t$ や t 値を見てから決めていない。** 上位5年は 2010(9.67)・2023(9.50)・2020(7.31)・2018(5.45)・2013(4.68)、中位年は 2004(2.32)、全年平均 3.072。

> **ラベルについて。** target は **(A)–(E)** とする。`T##` は本プロジェクトの todo 番号（T1 = サプライズ分解、T4 = 2010年イベント…）に予約されていて、**番号は一度振ったら再利用しない**という規約がある（`261004_goals_and_todo.md` §4）。初稿で target を T1–T4 と書いていたのは衝突なので、正式化にあたって改めた。

### 3.1 一番素直な target は符号が逆

**(A) は $-0.000798$ で、プール値 $+0.001580$ と符号が逆。** $\hat\delta_{\text{pool}}/\hat\theta_A = -1.98$。

「24年を等しく扱った平均的な緩和効果」は、報告されてきた値の約2倍の大きさで**反対を向いている**。

**ただし語調は抑える。** CI [-0.00351, +0.00192] はゼロを含むので、**「等重み平均は負である」とは書けない**。書けるのは「**符号を含めてゼロと区別できない。報告値 +0.00158 はこの区間の中にあるが、点推定としては符号が逆である**」まで。

### 3.2 精度の代価は target 次第（「必ず失う」は誤り）

| target | SE/SE(プール) |
|---|---|
| (A) 等重み | **1.51倍** |
| (B) 曝露加重 | **0.94倍** |
| (C) 高曝露5年 | 1.06倍 |
| (D) $\delta_{2010}$ | 2.34倍 |

**(B) の SE はプールより小さい。** プール値の重みは「分散を最小化する重み」ではないので（重みは**交差積**であって分散ではない、outline §3.2）、重みを経済的に意味のあるものに取り替えると精度が落ちるとは限らない。

**(A) が 1.51倍で済むことも重要である。** 「解釈可能な estimand に替えると推定できなくなる」という反論は、この設計では数値的に成立しない。失うのは1.5倍で、(A) がゼロと区別できないのは**SE が膨らんだからではなく点推定が小さいから**である。

### 3.3 汚染合計の Conley（T20 §3.2 への補足）

汚染**合計**（3項の和）は**クラスター t 2.47、Conley 50km t 1.60** で、Conley では 5% に届かない。

T20 §3.2 と outline §6.5 が報告しているのは `heat × coast` **単独**（クラスター 4.71 / Conley 2.34）である。**合計は別の量で、`heat` 主効果由来（-5.2%、t -0.91）と `heat × forest` 由来が足し込まれる分だけ比が悪化する。** §6.5 の表に合計を足すなら、**「`coast` 単独は両方の VCV でゼロを除外するが、汚染合計は Conley ではゼロを含む」**と書き分ける。T20 の結論は変わらない（`coast` 単独の話なので）。

### 3.4 Conley の診断：7つの量で Conley SE がクラスターより小さい（破綻ではない）

T12 §2 は「**Conley SE がクラスターより小さくなるのは数値的な破綻である**」を診断基準として立てた（200km で SE がクラスターの42分の1になった件）。本稿の量のうち **7つがこの基準に引っかかる**。

| 引っかかった量 |
|---|
| プール $\hat\delta$（$1.72 \to 1.85$） |
| (A) 等重み平均（$-0.58 \to -0.79$） |
| (A) の gap と重みのずれ、(B) の gap と重みのずれ、(D) の重みのずれ |

**しかしこれは破綻ではない。** 根拠は2つ。

1. **Conley VCV は正定値である。** 167次元の固有値は**最小 9.9e-17・負の個数 0**。二次形式が負になった量も **0個**（クランプは働いていない）。T12 の 200km は最小固有値 1.0e-16 で `fixest` が「VCOV が正定値でないため修正した」と警告を出していたが、**50km ではその警告が出ない**。
2. **fixest の Conley は市町村クラスターを入れ子に含む。** 合成データで確認した：2ユニットを cutoff の外（2,000km）に置いて AR(0.9) の系列相関を入れると、**Conley 50km SE × $\sqrt{G/(G-1)}$ がクラスター SE に一致する**（0.04356 × 1.414 = 0.0616 対 0.06121。HC1 は 0.302 で桁が違う）。つまり **Conley は一様カーネルで、同一市町村の異時点ペア（距離 0）を含んでいる**。

   よって Conley とクラスターの差は **(i) 小標本補正**（クラスターは $G/(G-1)$、$G=209$ で 1.005 なので無視できる）と **(ii) 市町村間の空間共分散**だけである。**Conley < クラスターは「空間共分散が差し引きで負」を意味する。**

**どちらを見出しにするか。** 空間共分散が負なら Conley は**保守的でない**ので、**見出しの数値はクラスターで報告し、Conley は参考に併記する**（§3 の表はこの方針で作ってある）。

**T12 §2 の基準は撤回しない。** あの基準は「cutoff を広げすぎると VCV の階数が落ちる」ことの検出に有効で、本稿も固有値で同じ検査をしている。**修正するのは適用範囲だけである**：負の重みを多く含む線形結合では、SE の大小だけで破綻を判定せず、**固有値と SE の大小を分けて見る**（スクリプト §D がこの2つを出す）。

> **なぜ空間共分散が負になるのか**は本稿では開けていない。引っかかった7つはいずれも**年を跨いで符号の違う重みを大きく載せる量**（(A) は 2010年に +0.231、他の年に -0.04 前後）なので、隣接市町村の残差が年を跨いで逆向きに動く成分を拾っている可能性がある。**本文では機序を主張せず、「クラスターで報告する」という処理の根拠だけ書く。**

**汚染列は全行で同一（+0.000342）**。§2.2 の代数のとおりである。

### 4.1 (C)：§2.2 の予告が数値で確認された

outline §2.2 は「**連続処置のプール TWFE は機械的に極端年の推定量になる。これは本標本の偶然ではなく設計クラスの性質である**」と予告している。

**(C) とのギャップは t = 0.78 で有意でない。** しかも**重みのずれの寄与がわずか 9.7%**（+0.000037）で、残り 90.3% は汚染である。すなわち

> **プール値は「高曝露5年の平均効果」から、重みの意味では区別できない。** 残っている差はほとんど汚染だけである。

これは §2.2 の主張を**予告ではなく結果として**書けるようにする。現行の §2.2 は分布の性質（ゼロ 37.1%、中央値1日）と $\omega$ の集中（87.2%）から**論理的に**言っているが、T21 は**プール値と「極端年の平均」との距離が統計的にゼロである**ことを直接示す。

### 4.2 主張は弱まるのではなく鋭くなる

(C) の結果は一見「プールでも悪くない」に見えるが、書くべきことは逆である。

> **estimand は存在する。ただしそれを選んだのは研究者ではなく設計である。**

(C) は「高曝露5年」という**曝露分布だけから決まる target** で、研究者が「平均的な緩和効果を知りたい」と思って立てた target（(A)(B)）ではない。プール値が近いのは前者で、遠いのは後者である（(A) gap t 1.88、**(B) gap t 2.77 で5%有意**）。

**これは de Chaisemartin–D'Haultfœuille の論点そのものである。** 推定量が何かを識別していることは、それが知りたかったものであることを意味しない。§3.3 の4点（なぜ misspecification ではなく estimand で語るか）に、**第5点として「距離が測れる」を足せる**。

### 4.3 (D)：「寄与 87.2%」は「$\delta_{2010}$ に近い」ではない

**(D) とのギャップは -0.003474、t = -2.37 で5%有意。** プール値 +0.00158 は $\delta_{2010}$ = +0.00505 の **31%** にすぎない。

**現行本文はこの区別をしていない。** 「2010年の寄与 87.2%」と書くと「プール値はほぼ $\delta_{2010}$ である」と読まれるが、違う。寄与率は $w_{D,2010}\hat\delta_{2010}/\hat\delta_{\text{pool}}$ で、**$w_{D,2010} = 0.273$ が 1 ではない**ので値は一致しない。残りの23年が合計 **-8.9%** 分を押し戻して主項が 78.4%、そこに汚染が **+21.6%** 足されて +0.00158 に落ち着く（87.2 - 8.9 + 21.6 ≈ 100）。

**書き方：「重みは 2010年に集中しているが、プール値は $\delta_{2010}$ でもない。」** これは重み集中の主張を弱めない。**どの単一年の効果でもなく、どの平均でもない値が報告されてきた**という、より強い言い方になる。

### 4.4 (A) の gap は5%に届かない

**(A) の gap は t = 1.88** で 5% に届かない（CI の下限 -0.00010 がわずかにゼロを跨ぐ）。有意なのは **(B) と (D)** だけである。

**したがって「プール値は等重み平均から有意に離れている」とは書けない。** 書けるのは次の形である。

- **(B) に対しては有意に離れている**（t 2.77）
- **(D) に対しては有意に離れている**（t -2.37）
- **(C) に対しては離れていない**（t 0.78）
- (A) に対しては **10% 水準でのみ**離れている（t 1.88）

**この並びが本稿の主結果である。** プール値は「極端年の平均」に一致し、「研究者が立てた平均」からは離れる。
