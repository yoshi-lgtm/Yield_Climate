## 1. 本番スペックの選び方（検定統計量では選ばない）

T4 §2.6 で `coast`+`elev` を「全スペック中最良」と書いたが、これは **$\chi^2(23)$ で順位づけた結果であり、報告する当の検定の統計量でスペックを選ぶ post-selection である**。`261004_goals_and_todo.md` §3.2 で「$\omega_t$ で比較対象を制限するのは同じデータで対象を選ぶ post-selection になる」として年 permutation を落としたのと同じ誤りにあたる。**撤回する。**

選択基準は**事前の機序**とする（§3.7 の「事前に決める」方針と整合）。

| 変数 | heat の**限界**被害を修飾する機序 | 判定 |
|---|---|---|
| **`coast`**（海岸距離） | 海洋性の緩和。海風・日較差の縮小・高湿度。暑い日1日あたりの被害を直接左右する | **あり → 本番** |
| **`forest_nbr`**（田の3×3近傍の森林率） | 局所の遮蔽・蒸散冷却・冷気流出 | **あり → 本番** |
| `elev`（標高） | 逓減率は気温の**水準**に効くが、水準は HD35 自体に既に入っている。限界被害を修飾する理屈は弱い | 弱い → 頑健性 |
| `lat` / `lon` | **ない。** 座標そのものに機序はない | なし → 頑健性 |

**識別の面でも機序ベースのペアが優れている。** 推定標本（209市町村）での相互相関は

| ペア | 相関 | 両方有意か |
|---|---|---|
| **`coast`+`forest_nbr`** | **0.110** | **両方**（T4 §2.7：-3.78 / +2.57） |
| `coast`+`elev` | 0.667 | `coast` のみ（`elev` は t = -0.65） |
| `forest_nbr`+`elev` | 0.666 | 係数が暴れて解釈不能 |

$\chi^2$ で選んだ `coast`+`elev` は2変数の相関が 0.667 もあり、`elev` が潰れていただけである。**機序で選んだペアが、唯一きれいに識別できるペアでもある。**

## 2. 恒等式の一般化

プール式に年別の競合交差項が入ると、汚染項が増える。$D = h\cdot c$、$G = h\cdot\text{coast}$、$F = h\cdot\text{forest}$ として

$$y = \alpha_i + \tau_t + \sum_t \mathbb{1}[t]\big(\beta_t h + \delta_t D + \gamma_t G + \eta_t F\big) + \sum_t \mathbb{1}[t]\big(c_i + \text{coast}_i + \text{forest}_i\big) + \gamma X + \varepsilon$$

$\tilde D$ を $D$ の「他の全プール回帰子」への射影残差とすると

$$\hat\delta_{\text{pool}} = \underbrace{\sum_t w_{D,t}\hat\delta_t}_{\text{主項}} + \underbrace{\sum_t w_{h,t}\hat\beta_t}_{\text{汚染1：heat}} + \underbrace{\sum_t w_{G,t}\hat\gamma_t}_{\text{汚染2：coast}} + \underbrace{\sum_t w_{F,t}\hat\eta_t}_{\text{汚染3：forest}}$$

$$w_{A,t}=\frac{\sum_i \tilde D_{it}A_{it}}{\sum_s\sum_i \tilde D_{is}^2}$$

**年×水準項・$X$・FE は $\tilde D$ と直交するので寄与しない。** $\tilde D$ が飽和式の張る空間に属するので、恒等式は有限標本で厳密に成立する。

## 3. 結果：3段のはしご

|---|---|---|---|
| プール $\hat\delta$ | +0.001404（t 1.80） | +0.001022（t 1.08） | **+0.001580（t 1.73）** |
| **主項** | +0.001663（t 2.24） | +0.000775（t 0.87） | **+0.001238（t 1.35）** |
| 汚染（heat, $\beta_t$） | **-0.000260（-18.5%、t -4.36）** | +0.000247（+24.2%、t +2.21） | **-0.000082（-5.2%、t -0.91）** |
| **汚染（coast, $\gamma_t$）** | — | — | **+0.000446（+28.2%、t +4.71）** |
| 汚染（forest, $\eta_t$） | — | — | -0.000021（-1.4%、t -0.51） |

### 3.1 汚染項の正体が入れ替わった

これが T18 の最大の結果である。

> **T11/T15 の汚染項は「$\beta_t$ 由来の何か」で、名前がなかった。本番スペックでは heat 主効果由来は -5.2%（t = -0.91）で有意ですらなくなり、代わりに `heat × coast` 由来が +28.2%（t = +4.71）を占める。**

すなわち

> **報告されている「圃場整備の高温害緩和効果」の約3割は、実は「海洋性の緩和効果」である。**

これは de Chaisemartin & D'Haultfoeuille (2020) の**複数処置の汚染**そのものであり、しかも**汚染源を物理的に名指しできる**。「推定値の一部が別のパラメータである」という抽象的な主張から、「報告値の28%は海岸からの距離の効果である」という具体的な主張になった。

`forest` 由来の汚染は -1.4%（t = -0.51）で無視できる。**森林は $\delta_t$ の推定を歪めてはいない**（T4 §2.7 で2010年の地理変動は説明するが $\delta_t$ の年次散らばりは縮めない、としたのと整合）。

### 3.2 重みの集中は復活する

年×`consol30` の飽和（T15）で 2010年の寄与は 90.9% → 53.8% に落ちたが、地理を統制すると **87.2%** に戻る。

| 年 | $\omega_t$ | $\hat\delta_t$ | 寄与 | プール値比 |
|---|---|---|---|---|
| **2010** | **0.2727** | **+0.00505** | +0.001378 | **87.2%** |
| **2023** | **0.2130** | +0.00080 | +0.000171 | **10.8%** |
| 2012 | 0.1597 | +0.00100 | +0.000160 | 10.1% |
| 2020 | 0.0782 | -0.00044 | -0.000035 | -2.2% |
| **2015** | 0.0591 | **-0.00727** | -0.000430 | **-27.2%** |
| 2018 | 0.0552 | -0.00035 | -0.000019 | -1.2% |
| 2019 | 0.0526 | -0.00070 | -0.000037 | -2.3% |
| 2013 | 0.0377 | +0.00094 | +0.000035 | 2.2% |

**重み 0.059 しかない2015年が、プール値の 27.2% を引き算している。** 負の重みは8年残る。

### 3.3 看板の数値は弱まる（正直に書く）

`research_portfolio_summary.md` と `261004_goals_and_todo.md` の目玉は

> 同程度の重みを持つ2年で $\delta_t$ が約**29倍**違い、プール推定値はどちらの年も記述していない

だった。本番スペックでは

| | T11 | **本番（T18）** |
|---|---|---|
| $\omega_{2010}$ / $\omega_{2023}$ | 0.359 / 0.286（比 1.26） | 0.273 / 0.213（比 **1.28**） |
| $\delta_{2010}$ / $\delta_{2023}$ | +0.00356 / +0.00012（比 **28.7倍**） | +0.00505 / +0.00080（比 **6.3倍**） |
| 寄与 | 90.9% / 2.5% | **87.2% / 10.8%** |

**比は 28.7倍から 6.3倍に落ちる。** 28.7倍という数字は $\delta_{2023}$ がたまたまゼロに近かったことに依存していた。

**ただし言いたいことは変わらない。** 重みがほぼ同じ（1.28倍）2年で寄与が 87.2% 対 10.8% であり、さらに重み 0.059 の2015年が -27.2% を引く。**本文では比ではなく寄与の対比で書く**のが頑健である。

### 3.4 (a) と (c)

- **(a) $\delta_{2010}$ = +0.00505（t = 2.35、p = 0.019）**。Conley 50km でも **t = 2.32**。全スペック中で最大かつ唯一 5% を明確に超える。ただし T4 §2.1 のとおり地理スペックを変えると 0.95〜2.35 に散らばるので、**これを根拠に (a) を主張しない**（根拠にすれば §1 で斥けた post-selection と同じになる）。IM は未実施
- **(c) $\chi^2(23)$ = 37.1、p = 0.032**。5%で棄却されるが「決定的」ではない。**Conley は (c) に使えない**（139.6。T12 §5.1 のとおり VCV が非正定値）

### 3.5 係数が微小であることは問題か（2026年10月23日に追加）

$\hat\beta \approx-0.004$、$\hat\delta \approx+0.005$ はいかにも小さく見える。**しかし係数の大きさは、推定の質について何の情報も持たない。** 単位の取り方の問題である。

#### (a) 数値計算上の問題はない

| 診断 | 値 | 判定 |
|---|---|---|
| 残差化デザイン行列の条件数 | **141.0** | 危険域は $>10^8$。**問題なし** |
| 列のSD の幅 | 0.489 〜 67.5 | 2桁程度。FE 除去後に QR で解いており無害 |
| 恒等式の誤差 ÷ $\hat\delta$ | $2.9\times10^{-14} / 1.6\times10^{-3} \approx 1.8\times10^{-11}$ | 倍精度の相対精度 $10^{-16}$ に対して十分上、意味のある量に対して十分下 |

#### (b) OLS は尺度変換に同変なので、係数の大きさには情報がない

`heat` を100倍して再推定した。

| | 元 | 100倍後 | 差 |
|---|---|---|---|
| $\delta_{2010}$ | +0.005055 | +0.00005055 | **比 100.0000** |
| **t 値** | +2.351858 | +2.351858 | **4.5e-11** |
| within $R^2$ | 0.34657904 | 0.34657904 | **0** |

**仮に heat を「100日単位」で測っていれば係数は100倍に見えたが、何一つ実質は変わらない。** 本稿が報告する量はすべて比か尺度不変である — t 値、$\chi^2$、$\omega_t$、寄与率（87.2%）、汚染項の割合（28.2%）。**したがって「係数が小さい」は論点にならない。**

#### (c) 実質的な大きさはむしろ大きい

単位は「HD35 1日あたり × 整備率1単位」である。2010年の実際の曝露（平均 HD35 = **9.67日**）に当てはめると

| | 係数 | 2010年の実質 |
|---|---|---|
| $\beta_{2010}$ | -0.00389 /日 | **-3.76%**（9.67日ぶん） |
| $\delta_{2010}$ | +0.00505 | 整備率を四分位間（0.021→0.651）動かすと **+3.08%**、10–90%分位（0.000→0.951）なら **+4.65%** |
| $\gamma_{2010}$（coast） | -0.00629 | 海岸距離 +1SD で **-6.08%** |

断面に直すと

| | 2010年の被害 |
|---|---|
| 整備率 10%分位の市町村 | **-3.76%** |
| 整備率 90%分位の市町村 | **+0.89%** |
| （参考）2010年の実際の収量偏差 | **-4.66%** |

**実際の2010年の落ち込み（-4.66%）と同じ桁である。** 対数収量の係数なので、この範囲では log ≈ % として読んでよい。

#### (d) ただし、ここに別の警告がある

$\delta_{2010}$ の含意は「整備率が高い市町村では2010年の高温被害が**完全に相殺される**（-3.76% → +0.89%）」である。**農学的にはこれは強すぎる。** 点推定が上振れしている可能性が高く、これは T18 §3.4 で「$t=2.35$ を根拠に (a) を主張しない」とした判断を別の角度から支持する。

#### (e) 小ささが本当に効いてくる場所

数値ではなく**精度**である。本番のプール $\hat\delta$ = +0.00158（SE 0.00091、**t = 1.73**）は有意ではない。したがって「汚染 28.2%」は**それ自体が不確かな量の 28.2%**である。

ただし内訳を見ると含意は逆方向に鋭くなる。

| | 値 | t |
|---|---|---|
| 主項（$\delta_t$ 由来） | +0.00124 | **1.35** |
| **汚染（`heat × coast` 由来）** | +0.00045 | **4.71** |

> **プール係数の中で精度よく測れているのは、関心のあるパラメータではない方である。** 主項は t = 1.35、汚染項は t = 4.71。

両方が精確な場合よりも、むしろ強い告発になっている。**本文ではこの対比をそのまま書く。**

## 4. 本番スペックの確定

$$\ln y_{it} = \alpha_i + \tau_t + \sum_{t\neq 2000}\mathbb{1}[t]\big(c_i + \text{coast}_i + \text{forest}_i\big) + \sum_t \mathbb{1}[t]\big(\beta_t h_{it} + \delta_t h_{it}c_i + \gamma_t h_{it}\text{coast}_i + \eta_t h_{it}\text{forest}_i\big) + \gamma X_{it} + \varepsilon_{it}$$

| | 扱い |
|---|---|
| 年 × `consol30` の飽和 | **本番**（T15。全年固有ショックの `consol30` 線形成分を吸収） |
| `coast`・`forest_nbr` の年飽和 | **本番**（機序あり、相互相関 0.110） |
| `elev` | 頑健性（機序が弱い） |
| `lat` / `lon` | 頑健性（機序なし） |
| 地理なし（T15 のみ）・年×c なし（T11） | 頑健性＝「何を統制すると何が消えるか」の提示 |

**選択基準を本文に明記する。** $\chi^2$ で選べば 24.1 まで下げられるが post-selection なので採らない、と書く。

## 5. 論文への含意

1. **主結果は強くなった。** 恒等式は4項でも機械精度で成立し、汚染項に**名前が付いた**（`heat × coast`、+28.2%、t = 4.71）
2. **看板の数値は弱くなった。** 28.7倍 → 6.3倍。**寄与の対比（87.2% 対 10.8%、2015年が -27.2%）に書き換える**
3. **(c) は「決定的に棄却」から「5%で棄却」へ。** T12 §8・`261004_goals_and_todo.md` §3.7 の記述を本番スペックの値に差し替える
4. **(a) は t = 2.35 まで上がるが、informative null の方針は維持する。** 地理スペック依存（0.95〜2.35）であり、有意になるスペックを選ぶのは post-selection
5. **「プール推定量は何を識別しているか」への答えが具体的になった。** 「年別効果の加重平均＋$\beta_t$ 由来の汚染」から「**2010年に 87% を負い、2015年が -27% を引き、報告値の 28% は海洋性の緩和である**」へ
