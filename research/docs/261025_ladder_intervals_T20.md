## 1. 経路依存の開示

**地理統制の採用には研究者の自由度が働いている。** 日付で確認できる事実を並べる。

| 日付 | 出来事 |
|---|---|
| 2026-09-23 | **群馬依存が最初に記録される**（群馬除外で $\delta$ が +0.00140 → +0.00032 に落ちる） |
| 2026-10-10 | T4 の horse race の競合リストに「**標高・海岸距離**・`paddy_ratio`・`pipe`・経営規模」と記載（**地理データを取得する前**） |
| 2026-10-12 | T12 の IM で $\delta_{2010}$ が都県間で符号割れ、**群馬 +0.0153 が突出** |
| 2026-10-23 | T4 実行。**緯度・経度が予想外に効く**（$\chi^2$ 81.9 → 37.2 / 43.4） |
| 同日 | 標高を取得 → **棄却**（`lon` と同時だと t -0.46）。海岸距離 → **効く**。森林 → 効く（別経路） |
| 同日 | T18 で汚染項を再計算、T19 の IM で**群馬が事後的に説明された** |

**正直に書くべきこと3点。**

1. **競合リストは群馬を知った後に書かれている**（9/23 の群馬 → 10/10 のリスト）。ただしリストは地理データを取得する前に固定されており、実際に効いたのは当初リストになかった**経度**で、リストにあった**標高は棄却された**
2. **群馬は地理統制の動機ではなく、統制の結果として事後的に説明された。** 順序は「群馬 → 地理統制」ではなく「地理統制 → 群馬が説明された」である（T19 は T18 の後）
3. **最も問題のある自由度は、筆者が一度 $\chi^2(23)$ を最小化するスペック（`coast`+`elev`、24.1）を「最良」として選んだことである。** これは報告する当の検定の統計量でスペックを選ぶ post-selection であり、撤回して**事前の機序による選択**に切り替えた。この訂正で主題の検定は $\chi^2$ = 24.1（p = 0.40）から **37.1（p = 0.032）へ不利な方向に動いた**

**§2 の表は、この経路依存に対する読者の防御として置く。** 何を足すと何が動くかを全部見せれば、特定の一段を選んだことの影響が読者に評価できる。

## 2. 統制を順に追加した表

追加の順序は**事前の機序で固定**し、統計量を見て並べ替えていない。

| | 追加するもの | 根拠 |
|---|---|---|
| R0 | 素のプール（FE ＋ $h$ ＋ $D$ ＋ $X$） | T11 |
| R1 | ＋年×`consol30` の水準 | 年固有ショック（2010年の政策ショックを含む）の吸収 |
| R2 | ＋`heat × coast` を年飽和 | 海洋性の緩和 |
| **R3** | **＋`heat × forest` を年飽和** | **局所の遮蔽・冷気流出 ← 本番** |
| R4 | 参考：＋`heat × elev` | 機序が弱い |
| R5 | 参考：＋`heat × lat, lon` | 機序がない |

R4 は `elev` の汚染 -7.3%（t -0.69）、R5 は `lat` -13.9%（t **-2.11**）・`lon` +11.1%（t 0.99）を併せ持つ。**恒等式の誤差は全段で 2.9e-14 〜 3.9e-13。**

### 2.2 読み方

**① 決定的な一段は R1 → R2（`coast` の追加）である。**

$\chi^2$ は 81.9 → 33.7、$\mathrm{sd}/\overline{SE}$ は 2.17 → 0.80。**$\hat\delta_t$ の散らばりが標本誤差並みまで落ちるのはここで起きる。** R3 以降は細部の調整にすぎない（0.80 → 0.76 → 0.72 → 0.74）。

**② 汚染項に名前が付くのも R2 である。** R0/R1 では「$\beta_t$ 由来の何か」（-18.5% / +24.2%）だったものが、R2 で `heat × coast` 由来 **+33.7%（t 4.42）**に置き換わり、heat 由来は +8.9%（t 1.27）へ縮む。R3 では heat 由来が **-5.2%（t -0.91）で有意ですらなくなる**。

**③ R4 は `elev` を本番から外す理由を数値で示す。** `elev` を足すと汚染項が**断片化する** — `coast` が 33.7% → **9.5%（t 4.42 → 1.05）**、`forest` が -1.4% → +15.7%、`elev` 自身が -7.3%。相関 0.667 で分解が3つに割れるだけで、**どれも解釈できなくなる**。$\chi^2$ が 35.7 と下がることを理由に採らないのではなく、**汚染項の名前が失われることを理由に採らない**。

**④ R5 も同様。** `lat` が -13.9%（t -2.11）を吸い、`coast` の t は 4.71 → 1.98 に落ちる。機序のない変数が、機序のある変数の解釈を奪う。

## 3. 区間推定（本番スペック R3）

| 対象 | VCV | 推定値 | t | **95% 信頼区間** |
|---|---|---|---|---|
| **$\delta_{2010}$** | 市町村クラスター | +0.005055 | +2.35 | **[+0.00084, +0.00927]** |
| **$\delta_{2010}$** | Conley 50km | +0.005055 | +2.92 | **[+0.00166, +0.00845]** |
| **$\delta_{2010}$** | **IM (G=6)** | **-0.000544** | **-0.48** | **[-0.00349, +0.00240]** |
| **汚染 coast** | 市町村クラスター | +0.000446 | +4.71 | **[+0.00026, +0.00063]** |
| **汚染 coast** | Conley 50km | +0.000446 | +2.93 | **[+0.00015, +0.00074]** |
| 主項 | 市町村クラスター | +0.001238 | +1.35 | [-0.00056, +0.00303] |
| 主項 | Conley 50km | +0.001238 | +1.48 | [-0.00040, +0.00288] |

### 3.1 informative null を区間で言う

> **IM の上限 +0.00240 は、クラスターの点推定 +0.00506 の半分以下である。**

これは「棄却できない」より強い言明である。実質に直すと（2010年の平均 HD35 = 9.67日、`consol30` の四分位間幅 0.63）

| | 整備率を四分位間で動かしたときの2010年の緩和 |
|---|---|
| クラスターの点推定 | **+3.08%** |
| **IM の上限** | **+1.46%** |
| IM の下限 | -2.13% |

**「効果があるとしても、クラスター推定値が示す大きさの半分以下である」と区間で言える。** T18 §3.5 で「$\delta_{2010}$ の含意（高整備率で2010年の被害が完全相殺）は農学的に強すぎる」と書いた警告が、区間推定でも裏づけられた。

### 3.2 汚染項はどちらの VCV でもゼロを除外する

クラスター [+0.00026, +0.00063]、Conley 50km [+0.00015, +0.00074]。**Conley で t が 4.71 → 2.93 に落ちるが、区間はなおゼロを含まない。** 空間相関を入れても「報告値の約3割は海洋性の緩和効果である」は保たれる。

主項は両方でゼロを含む（[-0.00056, +0.00303] / [-0.00040, +0.00288]）。**プール係数の中で区間がゼロを除外するのは汚染項の方だけ**という §T18 の対比が、区間でも再現される。

## 4. 汚染項に IM が使えない理由（構造的な制約）

**汚染項 $\sum_t w_{G,t}\hat\gamma_t$ は $\gamma_t$ の年次変動から生じる。** したがって IM に乗せるには都県ごとに $\gamma_t$ を年別に推定する必要があるが、

1. **都県別の年飽和は推定不能。** T19 §1.1 のとおり神奈川（8市町村・177行）では**41個の係数が共線で落ちる**。本稿で実際に走らせると、分解が成立するのは**千葉のみ**だった
2. **粗視化すれば可能になるが、粗視化が汚染項を壊す。** 年を4期（6年ずつ）にまとめると都県別推定は全6県で通るが、**全標本での汚染項が +28.2% → +5.0% に縮む**（$\gamma$ の年次変動を平滑化してしまうため）

| 分割 | 全標本のプール $\hat\delta$ | 主項 | 汚染 coast |
|---|---|---|---|
| 年別（24） | +0.001580 | +0.001238 | **+0.000446（28.2%）** |
| 4期 | +0.002476 | +0.002320 | **+0.000125（5.0%）** |

参考までに4期分割での IM は、汚染 coast が平均 +0.000198（t = 0.35、p = 0.74、CI [-0.00125, +0.00164]）、主項が平均 -0.001346（t = -2.22、p = 0.077、CI [-0.00290, +0.00021]）。**全標本の4期版（+0.000125）と整合的ではあるが、年別の汚染項（+0.000446）を検定したことにはならない。**

> **これは (c) 同質性に IM が使えないのと同じ $G=6$ の階数制約である。** 23制約の Wald に階数5の VCV が足りないのと同様、年別の $\gamma_t$ を6群に分けて推定することができない。**本文では「汚染項の推論はクラスターと Conley で行い、IM は構造的に適用できない」と明記する。**

## 5. 論文への反映

### 5.1 軸

> **恒等式 → 重み集中 → 名前のある汚染 → 残ったもの**

| 段 | 主な材料 |
|---|---|
| **恒等式** | 4項の分解が有限標本で厳密に成立（誤差 2.9e-14）。DGP の仮定を要さない。尺度不変（T18 §3.5） |
| **重み集中** | $\omega_{2010}$ = 0.273 で寄与 87.2%、重み 0.059 の2015年が -27.2%、負の重みが 8/24。**ゼロ過剰な連続処置に構造的** |
| **名前のある汚染** | `heat × coast` 由来が **+28.2%（クラスター t 4.71／Conley t 2.93、どちらも区間がゼロを除外）**。§2 の表で R2 で名前が付く過程を見せる |
| **残ったもの** | 主項は区間がゼロを含む（t 1.35）。(a) は IM で区間 [-0.0035, +0.0024]。**残ったのは `coast`・`forest` の地理的修飾であって整備率ではない** |

### 5.2 本文と Appendix の切り分け

| 本文 | Appendix |
|---|---|
| 恒等式と4項分解 | **$\beta_t$ の非定常性**（検証はする。限界として言及し詳細は送る） |
| §2 の統制追加の表 | **被害関数の非対称性**（$H^+$ -0.00677 対 $H^-$ +0.00142、2.6倍） |
| 汚染項の推論（クラスター＋Conley、IM が使えない理由） | 窓の選択（T2・T16）、heat 指標の horse race |
| (a) の区間推定（3通り） | 機序の切り分け（`consol30` 対 `pipe`） |
| 経路依存の開示（§1） | 標高の棄却、緯度経度版 |
| 後半＝地理的修飾（`coast` t -3.78／`forest` t +2.57） | long difference、係数の尺度不変性 |
