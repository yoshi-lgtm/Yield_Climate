## 1. Goal

### G0. プール推定量が何を識別しているかを特定する（最優先・主結果）

連続処置 $D_{it} \equiv H^{+}_{it}\cdot c_i$（$c_i$ = `consol30`）を含むプール式

$$\ln y_{it} = \alpha_i + \tau_{p(i)t} + \beta H^{+}_{it} + \delta D_{it} + \gamma X_{it} + \varepsilon_{it}$$

について、$\tilde D_{it}$ を $D$ を他の全回帰子（FE・$H^{+}$・$X$）に射影した残差とすると、真の DGP が年別効果 $\delta_t$ を持つとき FWL から

$$\hat\delta=\sum_t \omega_t\,\hat\delta_t,\qquad \omega_t=\frac{\sum_i \tilde D_{it}\, D_{it}}{\sum_{s}\sum_i \tilde D_{is}^2},\qquad \sum_t\omega_t=1$$

が **plim ではなく有限標本で厳密に**成り立つ（$\tilde D$ が年別交差式の説明変数の張る空間に属するため）。

**$\hat\delta$ は年別効果の加重平均を識別している。** 重みは研究者が選んだものでも、経済的な意味を持つ量でもない。

> **【2026年10月11日 T11 で訂正】** 当初ここに重みを「残差化処置の年内分散 $\sum_i \tilde D_{it}^2$」と書き、そこから「重みは非負で和が1なので de Chaisemartin & D'Haultfoeuille (2020) の負の重みの問題ではない」と述べたが、**どちらも誤りだった**。
> - 正しい重みは**交差積** $\sum_i \tilde D_{it} D_{it}$ である。分散版は恒等式を再現しない（実測で 22〜93% ずれる）
> - 交差積版は符号が定まらず、**実測で 9〜12 年の重みが負**になる。非負性の主張は撤回する
> - したがって負の重みは本設計でも生じる。さらに $\beta$ と $\delta$ が両方とも非定常なとき、プール $\hat\delta$ には $\beta_t$ 由来の**汚染項**が乗る（実測で **-18.5%**）。これは同論文系列の**複数処置**の場合そのものであり、文献上の位置づけは弱まるのではなく**強まる**
>
> 詳細と数値は `omega_decomposition_T11.md`。系譜が Angrist (1998) 型の分散加重にあること、重みが研究者の選択でないことは変わらない。

**気候被害関数でこれが特に効く理由**：$\tilde D$ の年内分散は $H^{+}$ の大きさにスケールする。2010年は $H^{+}\approx 9.7-2.7\approx 7$、冷夏年はほぼ 0。したがって $\omega_t$ は**極端年に集中する**。これは気候被害関数の推定に構造的に内在する性質であり、`phenology_calibrated_2026-09.md` §6 の「極端年を増やせば識別が改善する」という処方がなぜ外れたのかも説明する。**極端年を足すと $\omega_t$ の分布が変わるだけで、$\delta_t$ の異質性は解消しない。**

**予想（T11 で確認済み）**：HD35 が 9.7 対 9.5 であることから $\omega_{2010}\approx\omega_{2023}$ になるはずである。一方 $\delta_t$ は片方が大きく正、片方がゼロ。すなわち

> **同程度の重みを持つ2年で $\delta_t$ が大きく異なり、プール推定値はどちらの年も記述していない。**

これが「プールする定式化が妥当でない」ことの、leave-one-year-out より精密な言明である。LOYO のパターン（2010年を抜くと消える／2023年を抜いても消えない）も、重みの重い年のうち $\delta_t$ が大きいのは2010年だけである、として定量的に説明される。

**予想は T11 で確認された。** $\omega_{2010}$ = 0.359、$\omega_{2023}$ = 0.286（比 1.26）に対し、$\delta_{2010}$ = +0.00356、$\delta_{2023}$ = +0.00012（比 **28.7倍**）。2010年の寄与がプール $\hat\delta$ の **90.9%** を占める一方、2023年は **2.5%** にとどまる。

> **同程度の重みを持つ2年で $\delta_t$ が約29倍違い、プール推定値はどちらの年も記述していない。**

さらに、プール $\hat\delta$ = +0.00140 は $\delta_t$ の加重平均**ですらない**。主項 +0.00166 と $\beta_t$ 由来の汚染項 -0.00026（**-18.5%**）の和である。詳細は `omega_decomposition_T11.md`。

### G1. 識別されている対象を推定する（2010年イベント）

G0 が否定的・診断的な半分、G1 が構成的な半分。推定対象を識別変動に一致させた設計として、2010年の高温ショックに対する被害の異質性（整備率別）を推定する。

**「2010年を正面から扱う」は「2010年だけで回す」ではない。** 2010年の断面では heat の地域差が恒常気候とほぼ同義（暑い市町村は毎年暑い）なので、市町村FEを外すと交絡が戻る。**パネルのまま年別係数を推定する**（T4）。

空間相関・少数クラスターへの対処は §3 に分離した。**都県ブロックの wild bootstrap は使わない**（理由は §3）。

### G2. 修論への橋を架ける

- 卒論の $E[\text{heat}]$ 構築（T1）は、修論の期待利潤 $\mathbb{E}[\pi_{ijt}]$ の $E[\text{heat}]$ とそのまま同じ対象になる
- $\omega_t$ 分解の含意は修論にも直接効く：**非定常な $\beta$ を推定段階に持ち込まない**（`research_portfolio_summary.md` §2「期待利潤の構築」(1)）
- 修論の動機づけは**降水リスクから気温リスクへ切り替える**（Sakurai 2025 §5.10。降水変数は Sakurai のモデルに入っていない）→ T0-3
- 大豆の湿害で押すなら、この文献群の外（転換畑の排水の農学）に根拠を取りに行く必要がある

- [ ] **T4. 2010年イベント（年別係数の推定）**（3〜4日）← G1 の実体

  主軸の式：

  $$\ln y_{it} = \alpha_i + \tau_{p(i)t} + \sum_t \mathbb{1}[t]\cdot\big(\beta_t H^{+}_{it} + \delta_t\, H^{+}_{it}\times c_i\big) + \gamma X_{it} + \varepsilon_{it}$$

  成果物は $\delta_t$ のプロット（2010年が跳ね、他年はゼロ周りで平ら）。**LOYO 表と同じ情報だが、robustness check ではなく estimand の推定結果として提示できる。** $\beta_t$ も同時に出るので T10・G0 と1本で済む。

  副として long-difference 版（$\Delta\ln y_i = \ln y_{i,2010}-\ln y_{i,\text{base}}$）を併記し、散布図1枚で見える形にする。base 年が任意なのが弱点なので副に留める。

  **検定すべきもの**：LOYO は「2010年を抜くとプール推定値が消える」しか示していない。**$\delta_{2010}$ が他年の $\delta_t$ と有意に違うこと**は別の検定であり、これが T4 の本体（§3 参照）。

  **関数形について計画を修正**：「T10 の非対称スペックを使う」は正しいが、**2010年の係数に対して折り畳みはほぼ何もしない**。2010年は平均HD35 9.67 に対し市町村平均が2.7前後なので、ほぼ全市町村が $H^{+}>0,\ H^{-}=0$ になる。折る意味があるのは**他の23年**（冷涼側の変動が $\beta$ に混ざるのを止め、プラセボ分布がきれいになる）。「折るのは2010年のためではなく比較対象の年のため」と理解して使う。

  **交互作用の horse race は頑健性ではなく本体。** $\delta$ の識別仮定は「heat 曝露を条件づけたとき、`consol30` と相関する他の市町村特性が高温被害を修飾しない」。標高・海岸距離・`paddy_ratio`・`pipe`・経営規模が全部 `consol30` と相関する方向にある。単一事象設計では「複数事象で頑健」という逃げ道がないため、これを本体に置く。

  **メカニズムの切り分け**：理論は「整備 → 用排水インフラ → 掛け流し・深水かんがい → 水温低下 → 高温害緩和」だが、`consol30` が測っているのは**区画の大きさ**である。水管理の話なら `pipe` の方が直接的。`consol30` で効いて `pipe` で効かないなら水温の物語は弱く、「大区画＝規模の大きい・経営能力の高い農家」という別解釈が残る。
  → **`analysis_review` §6.1 の列リストには `排水良好` と `農道_幅4m以上` があるが、§6.2 で構築したのは `consol30` と `pipe` だけ。乾田化の指標を第3の変数として作る。**

  `consol30` は2010年センサス（2月1日現在＝ショックの前）なので、2010年については測定時点が理想的。逆因果の懸念がない。

## 3. 推論の方針

単一事象・6都県という設計に対して、**仮定集合の異なる手法を並べ、どこで結論が一致しどこで割れるかを示す**。計量理論ゼミに対しては、この並置自体が内容になる。

| 手法 | 仮定 | 答える問い |
|---|---|---|
| **年をパーミュテーション単位にする randomization inference** | 年間の交換可能性 | 「2010年は特別か」に直接答える。$\delta_t$ を24年について推定し、$\delta_{2010}$ が残り23年の分布のどこに位置するかを見る。p の下限 1/24 ≈ 0.042 |
| **Ibragimov–Müller (2010)** | 都県内は任意の従属、都県間独立、群内で漸近正規 | G=6 でも妥当。都県別に $\delta$ を推定し、6個の推定値に t 検定。パネル内の市町村数（茨城44・千葉62・埼玉79・栃木30・群馬36・神奈川56 前後）なら群内推定は可能 |
| **Canay–Romano–Shaikh (2017)** | 近似対称性 | 同じ少数群設定の randomization test。IM の補完 |
| **Conley (1999) 空間HAC** | 距離減衰、cutoff 指定 | 都県×年FE 後に残る短距離相関。cutoff を 25/50/100/200 km で振って慣例的ベンチマークとして併記 |

### 都県ブロックの wild bootstrap は使わない

東京が落ちているので都県は**6ブロック**しかない。Rademacher weight の組み合わせは $2^6 = 64$ 通りで、達成可能な最小 p 値が $1/64 \approx 0.016$。検定のサイズも歪む。**G = 6 の wild cluster bootstrap は実務的に機能しない**（MacKinnon–Webb）。旧 T4 がこれを指定していたが**撤回する**。

### 都県×年FE 自体が対処でもある

入れると識別変動が都県×年内に限定され、空間相関の主因である共通ショックが落ちる。残るのは都県内・短距離の相関なので Conley で拾える範囲になる。ただし都県レベルの heat 変動を捨てるので検出力は落ちる。**年FE 版と都県×年FE 版を並べ、何がどれだけ失われるかを示す。**

### 事前に決めておくこと

`phenology_calibrated` §5.1 の 2009–2013 で $\delta$ = +0.00377（SE 0.00170）だったことから、2010年に絞って Conley を当てると $\delta_{2010}\approx +0.004$、SE 0.002〜0.003、**t は 1.5〜2** に着地する見込み。有意になるかは微妙。

**$\omega_t$ 分解を主結果に置いたので、論文は $\delta_{2010}$ の有意性に依存しない。** 有意にならなければ信頼区間を明示した informative null として報告する。閾値・窓の選択について既に決めた「事前に決める」方針を、ここにも適用する。
