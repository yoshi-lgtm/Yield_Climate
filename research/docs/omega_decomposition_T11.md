## 1. 恒等式と、重みの正しい形

プール式と年別交差式を

$$y_{it} = \text{FE} + X_{it}\gamma + b\,r_{it},\qquad y_{it} = \text{FE} + X_{it}\gamma + \sum_t b_t\, r_{it}\mathbb{1}[t]$$

とし、$\tilde r_{it}$ を $r$ を (FE, $X$) に射影した残差とする。FWL より $\hat b = \sum \tilde r y / \sum \tilde r^2$ で、$\tilde r$ は**年別交差式の説明変数が張る空間に属する**（$r=\sum_t r\mathbb{1}[t]$）ため、年別交差式の残差との直交性が効いて

$$\hat b=\sum_t \omega_t\,\hat b_t,\qquad \omega_t=\frac{\sum_i \tilde r_{it}\, r_{it}}{\sum_{i,t}\tilde r_{it}^2},\qquad \sum_t \omega_t = 1$$

が **plim ではなく有限標本で厳密に**成り立つ。

### 1.1 G0 の式は誤っていた

`goals_and_todo.md` G0 は $\omega_t \propto \sum_i \tilde r_{it}^2$（残差化処置の年内分散）と書いたが、正しくは交差積 $\sum_i \tilde r_{it} r_{it}$ である。両者は

$$\sum_i \tilde r_{it} r_{it} = \sum_i \tilde r_{it}^2 + \sum_i \tilde r_{it}\, p_{it} \qquad (p = \text{射影成分})$$

で、第2項は**全年の合計ではゼロだが年ごとにはゼロでない**。したがって年別には一致しない。数値でも分散版は恒等式を再現しない（§2）。

### 1.2 非負性は成り立たない

分散版 $\sum_i \tilde r_{it}^2$ は定義上非負なので、G0 が「重みは非負」と書いたのは**誤った式に対しては整合していた**。正しい交差積版は符号が定まらず、実際に負の年が出る（§3）。

**したがって G0 の「de Chaisemartin & D'Haultfoeuille の負の重みの問題ではない」という位置づけも撤回する。** 負の重みは本設計でも生じる。さらに §5 の汚染項は、同論文系列の**複数処置**の場合そのものである。文献上の位置づけは弱まるのではなく**強まる**。

## 3. 重みの分布

スペック(2)（$\delta$ の分解、heat はプール）の重み：

| | 値 |
|---|---|
| $\omega_{2010}$ | **0.35884**（最大） |
| $\omega_{2023}$ | **0.28580**（2位） |
| $\omega_{2020}$ | 0.13560 |
| $\omega_{2012}$ | 0.08927 |
| 上位3年の合計 | **0.7802** |
| 最小 / 最大 | -0.01024 / +0.35884 |
| $\omega_t<0$ の年数 | **12 / 24** |

スペック(1)（$\beta$）では $\omega_{2010}$ = 0.30361、$\omega_{2023}$ = 0.23893、上位3年 0.6725、負の年 9。

### 3.1 なぜ2010年と2023年の重みが近いのか

$\omega_t$ は $r$ の年内ばらつきにスケールする。`obs_HD35` の年平均と標準偏差は

| year | mean | sd |
|---|---|---|
| **2010** | **9.673** | **8.037** |
| **2023** | **9.503** | **7.565** |
| 2020 | 7.314 | 5.371 |
| 2012 | 4.278 | 5.825 |

**2010年と2023年は水準もばらつきもほぼ同じ**なので、重みがほぼ同じになる。これは機械的な帰結であり、`panel_extension` §5.1 の「2023年は2010年と同程度に暑かったが収量は落ちなかった」という観察の、推定量側での対応物である。

### 3.2 重みは「おかしい」のではなく「研究者の選択ではない」

$\omega_t$ が負または極小になるのは、その年に $r$ の変動がほとんどない年である。たとえば2009年は `obs_HD35` の平均が 0.01 しかなく、年別係数が $\beta_{2009}$ = -0.0198、$\delta_{2009}$ = +0.0402 と暴れるが、重みは $w_D$ = -0.00118 で実害がない。**重みは変動のない年を正しく捨てている。** 問題は重みが壊れていることではなく、**重みが研究者の選択でも経済的な意味を持つ量でもないまま、少数年に集中すること**である。

## 4. $\delta$ の分解

### 4.1 heat をプールに固定すると符号が逆転して見える

スペック(2)では $\delta_{2010}$ = **-0.000185**（ほぼゼロ）、$\delta_{2023}$ = **+0.002173** となり、LOYO の「2010年を抜くと $\delta$ が消える」と矛盾するように見える。

**これは $\beta$ をプールに固定したことの産物である。** 単一の $\beta$ は重みの大半を持つ2010年に引っ張られて強く負になり、他の年の $\delta_t$ がその行き過ぎを埋め合わせる。すなわちスペック(2)の $\delta_t$ は構造パラメータではない。

### 4.2 両方を年別にすると予想どおりになる

`log_yield ~ i(year, obs_HD35) + i(year, h_consol) + CTRL | city_id + year`

| year | $w_{D,t}$ | $\delta_t$ | 寄与 |
|---|---|---|---|
| **2010** | **0.35884** | **+0.003555** | **+0.0012756** |
| **2023** | **0.28580** | **+0.000124** | **+0.0000355** |
| 2020 | 0.13560 | +0.000223 | +0.0000302 |
| 2012 | 0.08927 | +0.002485 | +0.0002219 |
| 2015 | 0.02103 | -0.010653 | -0.0002241 |

重みの比 $\omega_{2010}/\omega_{2023}$ = **1.26** に対して、係数の比 $\delta_{2010}/\delta_{2023}$ = **28.7**。

**G0 の予想がそのまま確認された。** 2010年の寄与 +0.0012756 はプール $\hat\delta$ = +0.00140374 の **90.9%** を占める。2023年は重みが2010年の 0.80倍あるのに、寄与は **2.5%** しかない。

**同程度の重みを持つ2年で $\delta_t$ が約29倍違い、プール推定値はどちらの年も記述していない。**

## 5. 汚染項：プール $\hat\delta$ は $\delta_t$ の加重平均ですらない

$\beta$ と $\delta$ の両方が年別である DGP の下では、プール $\hat\delta$ の分解に第2項が立つ。$\tilde D$ を `h_consol` を (heat, $X$, FE) に射影した残差として

$$\hat\delta_{\text{pool}}=\sum_t w_{D,t}\,\hat\delta_t+\sum_t w_{Dh,t}\,\hat\beta_t,\qquad w_{D,t}=\frac{\sum_i \tilde D_{it}D_{it}}{\sum \tilde D^2},\quad w_{Dh,t}=\frac{\sum_i \tilde D_{it}h_{it}}{\sum \tilde D^2}$$

第1項が主項、第2項が汚染項である。$\sum_t w_{D,t}=1$、$\sum_t w_{Dh,t}=0$（$\tilde D \perp h$ は全年合計では成り立つため）。**年ごとにはゼロでないので汚染項は残る。**

| | 値 | プール値に対する比 |
|---|---|---|
| プール $\hat\delta$ | +0.00140374 | 100% |
| 主項 $\sum w_{D}\delta_t$ | **+0.00166324** | 118.5% |
| 汚染項 $\sum w_{Dh}\beta_t$ | **-0.00025951** | **-18.5%** |
| 合計（誤差） | +0.00140374 | -3.89e-13 |

数値確認：$\sum w_D$ = +1.0000000000、$\sum w_{Dh}$ = +0.0000000001。

**含意**：「圃場整備の緩和効果」として報告される +0.00140 のうち、18.5%は緩和効果ではなく**高温被害の主効果 $\beta_t$ の年次異質性が漏れ込んだもの**である。汚染項が負なのは、重みの重い年（2010・2023・2018・2019）で $w_{Dh}>0$ かつ $\beta_t<0$ であるため。

これは de Chaisemartin & D'Haultfoeuille の**複数処置**の議論そのものであり、§1.2 のとおり文献上の位置づけはむしろ強まる。

## 7. 含意と次の一手

### 7.1 主結果として書ける内容

1. **恒等式**（§1）。有限標本で厳密、機械精度で検証済み（§2）
2. **重みの集中**（§3）。上位3年で78%、2010年と2023年の重みがほぼ同じ
3. **同程度の重みで $\delta_t$ が29倍違う**（§4.2）。プール推定値はどの年も記述しない
4. **汚染項 -18.5%**（§5）。プール $\hat\delta$ は $\delta_t$ の加重平均ですらない

**4 が最も強い。** 1〜3 は「プール推定値の解釈に注意」だが、4 は「報告されている数値の18.5%は別のパラメータである」という定量的な主張になる。

### 7.2 T4 への含意

$\delta_{2010}$ = **+0.003555** が、年別に推定した2010年の緩和効果である。`phenology_calibrated` §5.1 の 2009–2013 推定値 +0.00377 とほぼ一致しており、T4 の見込み（$\delta_{2010}\approx+0.004$）は妥当だった。**T4 は推定ではなく推論（SE）の作業になる。**

### 7.3 残る作業

- SE。本稿の数値はすべて点推定で、$\omega_t$ の推定誤差も $\delta_t$ の SE も扱っていない。$\omega_t$ はデータの関数なので、$\sum\omega_t\delta_t$ の SE は delta method か bootstrap が要る → T12
