### 2.2 設計クラスとしての気候被害関数（この節が第6章を事前に保証する）

- [ ] 気候被害関数には構造的な特徴がある
  - 処置が**ゼロ過剰**（HD35 は**ゼロ 37.1%、中央値 1日**、平均 3.087日）
  - 曝露の年次変動が**極端年に集中**する
- [ ] したがって**連続処置のプール TWFE は機械的に極端年の推定量になる**。これは本標本の偶然ではなく**設計クラスの性質**である

- [ ] この性質が「水稲・高温害は題材（vehicle）」という転換を正当化する

## 3. What the pooled estimator identifies（データを使わない章）

### 3.1 恒等式

- [ ] プール式と年別飽和式を並べ、$\tilde D$ を $D=h\cdot c$ の「他の全プール回帰子」への射影残差と定義する
- [ ] $D = h\cdot c$、$G = h\cdot\text{coast}$、$F = h\cdot\text{forest}$ として

$$\hat\delta_{\text{pool}} = \underbrace{\sum_t w_{D,t}\hat\delta_t}_{\text{主項}} + \underbrace{\sum_t w_{h,t}\hat\beta_t}_{\text{汚染1}} + \underbrace{\sum_t w_{G,t}\hat\gamma_t}_{\text{汚染2}} + \underbrace{\sum_t w_{F,t}\hat\eta_t}_{\text{汚染3}},\qquad w_{A,t}=\frac{\sum_i \tilde D_{it}A_{it}}{\sum_s\sum_i \tilde D_{is}^2}$$

- [ ] **成立の論理**：$\tilde D$ が年別交差式の設計行列の張る空間に属する（$D=\sum_t D\mathbb{1}[t]$）ため、FWL から **plim ではなく有限標本で厳密に**成立する
- [ ] **年×水準項・$X$・FE は $\tilde D$ と直交するので寄与しない**ことを明記する

### 3.2 恒等式の性質

- [ ] $\sum_t w_{D,t} = 1$、**他の重みは全年合計ではゼロだが年ごとにはゼロでない** → だから汚染項が残る
- [ ] **重みは交差積**である。残差化処置の年内分散 $\sum_i \tilde D_{it}^2$ ではない（分散版は恒等式を 22〜93% 再現しない）
- [ ] **非負性は成り立たない。** 符号が定まらず、実測で負の年が出る
- [ ] **重みは研究者が選んだものでも、経済的な意味を持つ量でもない**
- [ ] **尺度不変**：OLS は尺度変換に同変。本稿が報告する量（t 値、$\chi^2$、$\omega_t$、寄与率、汚染項の割合）はすべて比か尺度不変
- [ ] $\omega_t$ に**推定誤差はない**（$X$ に条件付ければ回帰子行列だけの関数で定数）。したがって主項・汚染項は**固定ウェイトの線形結合**で、$\widehat{\mathrm{Var}}(\hat\delta)$ から直接出る。**delta method も bootstrap も要らない**
- [ ] **その直接の帰結として、target estimand との距離が測れる**（T21）。target を $\theta=\sum_t a_t\delta_t$ の形に取れば $\theta$ も $\hat\delta_{\text{pool}}-\hat\theta$ も**同じ飽和式の係数の固定ウェイト線形結合**で、同一の VCV から点推定・SE・CI が出る。ギャップは

$$\hat\delta_{\text{pool}}-\hat\theta=\underbrace{\sum_t(w_{D,t}-a_t)\hat\delta_t}_{\text{重みのずれ}}+\underbrace{\sum_t w_{h,t}\hat\beta_t+\sum_t w_{G,t}\hat\gamma_t+\sum_t w_{F,t}\hat\eta_t}_{\text{汚染（$a$ に依存しない）}}$$

- [ ] **汚染項は $a$ を含まない** → **どの target を選んでも汚染の寄与は同一**で、target の選択に依存する部分（重みのずれ）と依存しない部分が**代数的に分離している**。これは報告上の利点なので明記する

### 3.3 なぜ misspecification ではなく estimand で語るか（4点）

- [ ] **前提を飛ばさない。** $\delta_t$ が年で動くのに単一 $\delta$ を推定すれば、それは定義上 misspecification であり、$\omega_t$ 分解はそれを否定しない。問題は「**どちらの言い方が仮定が弱く、情報量が多いか**」である。**この前提を飛ばすと審査で最初に突かれる**
- [ ] ① **恒等式か条件文か。** misspecification は「飽和モデルが真なら」という条件文。恒等式は代数的事実で DGP について何も言わない
- [ ] ② **飽和モデルへ逃げる処方が、この設計では使えない。** 2009年は207市町村中 HD35 > 0 が**9市町村**、$\hat\delta_{2009}$ = +0.0402（**t = 5.14 は SE の破綻**）、$\omega_{2009}$ = -0.00118 でプール値に何も寄与していない。**飽和モデルは推定できるが解釈できない係数を含む**。他方「報告されてきた単一の数値は何か」は答えられる
- [ ] ③ **処方の失敗を予言できるのは estimand の側だけ**（§2.2 で予告した「極端年を足せ」の失敗）
- [ ] ④ **汚染項という量が特定できる。** 「間違っている」からは「報告値の 28% は海岸距離の効果である」は導けない
- [ ] ⑤ **距離が測れる**（T21）。「間違っている」は二値だが、恒等式は **target estimand までの距離に点推定と区間を付ける**。「$\delta_{2010}$ から -0.0035 離れている（t -2.37）」「高曝露5年の平均からは離れていない（t 0.78）」は misspecification の語彙では言えない
- [ ] **これは逃げではなく、設計が支えられる主張の上限を正確に取っている**と書く

### 3.4 なぜ年の分割が特権的なのか（審査で突かれる一点）

- [ ] **答え：恒等式は任意の分割について成立し、都県でも走らせてある**（$\sum_p\omega_p$ = 1.00000000、誤差 8.4e-14）
- [ ] **重み最大・寄与最大・「抜くと消える」単位が三者とも一致しない**

| 分割 | 重み最大 | 寄与最大 | 抜くと消える |
|---|---|---|---|
| 年 | 2010年 $\omega$ = 0.359 | 2010年 90.9% | 2010年 |
| 都県 | 埼玉 $\omega_p$ = 0.407 | 栃木 41.5% | 群馬（寄与は **6.9%**） |

- [ ] したがって **「LOYO 型の感度分析は estimand の分解の代わりにならない」が年方向と空間方向で二重に立つ。** 攻められる側ではなく攻める側に回す

- [ ] 実質的な損失は小さい：**パネルは関東の田面積の 94.9% をカバー**（茨城 100.0%・千葉 97.9%・栃木 94.2%・群馬 94.0%・埼玉 87.1%・神奈川 54.2%）、**東京は関東の 0.16%**

### 4.2 処置変数の正確な意味

- [ ] `consol30` は「市町村の田のうち整備済みの割合」**ではない**。正しくは **0.2ha 以上の区画に限ったとき、そのうち大区画（30a 以上）・ほ区均平が占める割合**（2010年農林業センサス農業集落カード、時間固定、平均 0.367、SD 0.351）
- [ ] **この言い換えを本文に明示する。** 極端な例として、田の9割が極小区画で残り1割が全部 1ha 以上の市町村は `consol30` = 1.0 になり「完全に整備済み」に見える
- [ ] 分母のカバー率は市町村レベルで**中央値 43.5%**（10%分位 5.8%、90%分位 77.5%）。主産県でも田の3〜6割しか分母に入っていない
- [ ] **ただし機械的な交絡ではない。** カバー率と `consol30` の相関は Pearson **0.094** / Spearman 0.133 で弱い。**系統的な歪みではなく測定誤差として扱う**
- [ ] 測定誤差の向きは自明でないが、**$\delta$ を過小に見せる方向が自然**であり、$\delta$ が有意になりにくいことの説明候補になる

### 4.4 heat の定義

- [ ] $\text{heat}_{it}$ ＝ **`obs_HD35`**：実測登熟期窓における日最高気温 **35.0℃以上の日数**
- [ ] **日数であって超過度合いを捨てている**こと（`HDD26`・`HDD27` との対比で正当化する — horse race で HD35 が勝った）

### 5.4 帰無仮説を3つに分け、手法を対応させる

- [ ] 表を出す

| | 帰無仮説 | 制約 | 使える手法 |
|---|---|---|---|
| **(a)** | $\delta_{2010}=0$ | 1 | 市町村クラスター／Conley (10–50km)／**IM（仮定が最も弱い）** |
| (b) | $\delta_{2010}=\overline{\delta_{t\neq2010}}$ | 1 | **扱わない（どの主張にも要らない）** |
| **(c)** | $\delta_1=\cdots=\delta_{24}$ | 23 | **市町村クラスターのみ** |

- [ ] **鍵になる制約**：クラスターロバスト VCV の階数は高々 $G-1$
- [ ] **Conley は (c) に使えない**（VCV が非正定値で統計量が 751〜2.7e12 と発散）。cutoff も**地域の直径 226km** に縛られ、100km で対の 68.9%・200km で 99.7% が入るので使えるのは **10–50km**（200km では SE が市町村クラスターの42分の1という破綻）
- [ ] **IM は (c) に使えない**（階数 $G-1=5 < 23$）
- [ ] **都県ブロックの wild bootstrap は G=6 で機能しないので撤回**（$2^6=64$ 通りで最小 p ≈ 0.016、MacKinnon–Webb）
- [ ] **年 permutation は記述統計に降格。** 理由を2段で書く
  - 理論：交換可能性が壊れる（**SE の最大/最小が 15.6倍**＝2000年 0.00814 対 2023年 0.00052、温暖化トレンド、対相関が lag 1 で +0.411 → lag 10 以上 +0.086 と減衰）
  - 実務：**2010年の順位は 2/24**（studentized で 3/24）で p は 0.083〜0.125。**最大は2009年**で、情報を持つ市町村が9しかない年に負ける
- [ ] **弱識別の年の扱いを事前に決めて書く**：2009年のような年の年別係数は**報告するが解釈しない**。$\omega_t$ を併記すれば読者が判断できる
- [ ] **`fixest` の Conley は市町村クラスターを入れ子に含むと明記する**（T21 §3.4）。一様カーネルで**同一市町村の異時点ペア（距離0）を含む**ので、合成データでは **Conley SE × $\sqrt{G/(G-1)}$ がクラスター SE に一致する**。したがって2本の差は**市町村間の空間共分散だけ**で、**Conley < クラスターは「空間共分散が差し引きで負」の意味**になる（$G=209$ で小標本補正は 1.005）
- [ ] **その帰結として、SE の大小だけで「破綻」を判定しない。** T12 §2 の基準（Conley < クラスターは破綻）は**単一係数には有効だが、負の重みを多く含む線形結合には単純には適用できない**。**固有値（非正定値性）と SE の大小を分けて見る**。T21 では7つの量が SE の基準に引っかかるが、**VCV は正定値（最小固有値 9.9e-17、負 0個）で破綻ではない**
- [ ] **その場合に見出しをどちらにするかを事前に決めて書く**：空間共分散が負なら Conley は**保守的でない**ので、**見出しはクラスター、Conley は参考に併記**

- [ ] **「寄与 87.2%」は「$\delta_{2010}$ に近い」ではない**：プール値は $\delta_{2010}$ の **31%**、差は **t -2.37 で5%有意**。$w_{D,2010}=0.273$ が 1 ではないので一致しない（87.2% － 他23年 8.9% ＋ 汚染 21.6% ≈ 100%）。**どの単一年の効果でもなく、どの平均でもない値が報告されてきた**という、より強い言い方になる
- [ ] **精度の代価は target 次第**：SE 比は (A) 1.51倍、**(B) 0.94倍（プールより小さい）**、(C) 1.06倍、(D) 2.34倍。**「正しい重みにすると必ず精度を失う」は誤り。** 重みは交差積で分散ではないから（§3.2）
- [ ] **(A) がゼロと区別できないのは SE が膨らんだからではなく点推定が小さいから**。「解釈可能な estimand に替えると推定できなくなる」という反論は数値的に成立しない
- [ ] **(A) の gap は t 1.88 で5%に届かない**（下限 -0.00010）。**有意なのは (B) と (D) だけ**だと正確に書く
- [ ] **IM は構造的に使えない**：target は $\delta_t$ の線形結合なので都県別の年飽和が必要で、神奈川で41係数が落ちる（T19）。粗視化は汚染項を壊す（§6.5 の最終項目と同じ $G=6$ の階数制約）

## 8. Discussion and conclusion

### 8.1 主張できること／できないこと（表で出す）

- [ ] **できる**：プール推定量の組成の特定（恒等式、無仮定）／**名前のある汚染項**（報告値の 28% は海岸距離の効果）／気候被害関数における重み集中の構造性／$\delta$ の見かけの異質性が時間・空間の両方向で同一の脱落交互作用に帰着すること／**target estimand までの距離に区間を付けること**（T21。プール値は「高曝露5年の平均」と区別できず t 0.78、「曝露加重平均」からは有意に離れる t 2.77、$\delta_{2010}$ からも有意に離れる t -2.37）
- [ ] **できない**：$\delta_{2010}$（IM で null）／水温経路の機序／「決定的に棄却」／**「等重み平均は負である」**（T21：点推定 -0.000798 だが CI [-0.00351, +0.00192] はゼロを含む。**符号は点推定の話**）

### 8.2 物語の型が変わったことを明示する（スピンではなく変更）

- [ ] **旧**：異質な $\delta_t$ を平均している → **新**：モデルに入っていない交互作用（空間×年）を $\delta$ に押し込んでいる
- [ ] $\beta_t$ 由来の汚染項と**同じ系統の現象**なので論文の筋は一貫するが、**書き換えであることを明記する**
- [ ] **この変更に耐えられたのは主結果を恒等式に置いたからである。** 「検定が棄却したからプールが悪い」と書いていたら、(c) が p = 0.032 まで弱まった時点で論文が崩れていた

### 8.3 限界（全部書く）

- [ ] **プール $\hat\delta$ 自体が有意でない**（t = 1.73、SE 0.00091）ので、「汚染 28.2%」は**不確かな量の 28.2%** である。ただし主項 t 1.35 対 汚染項 t 4.71 の**対比をそのまま書く**
- [ ] **`coast` と `lon` の総当たりは決着しない**（§7.1）
- [ ] **$\delta_{2010}$ の含意が農学的に強すぎる**（高整備率で2010年の被害が -3.76% → +0.89% と完全相殺）。**全標本の点推定は上振れしている**
- [ ] **神奈川は8市町村・177行**で、IM の群内漸近正規が怪しい（除外しても t = -0.85 で結論不変）。$\omega_p$ = 0.0027、`consol30` の分母カバー率 0.035。**寄与がほぼゼロなので残すが、限界として書く**
- [ ] **`consol30` の分母カバー率が中央値 43.5%**（測定誤差）
- [ ] **`forest_nbr` の近傍半径（3×3）の感度は未検証**
- [ ] **コントロールが窓ベースに揃っていない**（7–8月固定暦月）
- [ ] **$\beta_t$ の非定常性と被害関数の非対称性は検証はするが、限界として言及し詳細は Appendix に送る**
- [ ] **係数の微小さは論点にならないと書く**：heat を100倍すると係数は 1/100 になるが **t 値は 4.5e-11 の差で一致**し within $R^2$ は不変。条件数 141。報告する量はすべて比か尺度不変
- [ ] **target の重みは研究者が選んでいる**（T21）。(A) は推定量にもデータにも依存しないが、**(B)(C) は曝露分布から決めたとはいえ「なぜその3つか」は研究者の判断**である。§2 か §5 で**事前に**正当化し、§6.2.5 では5つ全部を同じ表に出す（選べば post-selection）
- [ ] **汚染「合計」の Conley はゼロを含む**（t 1.60）。ゼロを除外するのは `heat × coast` **単独**の方である（§6.5）

### 8.4 修論への接続（短く）

- [ ] $\omega_t$ 分解 → **非定常な $\beta$ を推定段階に持ち込まない**（推定段階は収量の移動平均、反実仮想段階のみ構造形）
- [ ] 被害関数の非対称性 → **キンクがあるので平均では足りない**。$E[H^+]$ は分布の形に依存するので「極端年の頻度が2倍」という反実仮想が平均気温と独立に効く
- [ ] 曝露窓が内生（GDD）→ **反実仮想気候のもとで出穂日を再計算してから曝露を測れる**（Sakurai 2025 の時間不変な作期に対する方法論的優位）

## 12. 解決済み：Conley の t 値（2026年11月2日）

### 12.1 結論

**T18 が正しく、T20 の Conley 列はすべて誤りだった。** typo ではなく**実装のバグ**である。

| 対象 | 誤（修正前の T20） | **正（修正後。T18 と15桁一致）** |
|---|---|---|
| $\delta_{2010}$ Conley 50km | SE 0.001732、t 2.92、CI [+0.00166, +0.00845] | **SE 0.002176、t 2.32、CI [+0.00079, +0.00932]** |
| 汚染 coast Conley 50km | SE 1.521e-04、t 2.93、CI [+0.00015, +0.00074] | **SE 1.900e-04、t 2.34、CI [+0.00007, +0.00082]** |
| 主項 Conley 50km | SE 8.365e-04、t 1.48、CI [-0.00040, +0.00288] | **SE 9.162e-04、t 1.35、CI [-0.00056, +0.00303]** |

**クラスターと IM の値は一切変わっていない**（係数も、クラスター SE も、$\chi^2$ も、恒等式の誤差も不変）。壊れていたのは Conley の VCV だけである。

### 12.2 原因

`t20_ladder_intervals.R` は R5（`heat × lat, lon`）のために **`lat` と `lon` を市町村断面で標準化**している（`coast`・`forest`・`elev` と同じループ）。ところが Conley の呼び出しが

```r
vcov_conley(ms, lat = ~lat, lon = ~lon, cutoff = 50, ...)
```

で**同じ標準化済みの列**を参照していた。すなわち **z 値を緯度経度として渡し、そこから計算した距離に「50km」の cutoff を当てていた**。近傍の定義そのものが無意味になる。

`t18_omega_mechanism.R` は `coast` と `forest` だけを標準化し、`lat`/`lon` を**度のまま**残していたので正しかった。T18 spec 1 の Conley SE が T12 の値（0.002128）を完全に再現していたのも、これで説明がつく。

### 12.3 事後的に見れば、兆候は出ていた

`261012_vcov_inference_T12.md` §2 は **「Conley SE は空間相関を足すので通常クラスターより大きくなるべきで、小さくなるのは数値的な破綻である」**と自分で書いている。修正前の T20 は

| | クラスター SE | Conley SE | 判定 |
|---|---|---|---|
| $\delta_{2010}$ | 0.002149 | **0.001732（小さい）** | 破綻の兆候 |
| 主項 | 0.000916 | **0.000836（小さい）** | 破綻の兆候 |

で、3つのうち2つがこの診断基準に引っかかっていた。**修正後は3つすべてで Conley > クラスターになる。** 自分の書いた診断基準を自分の出力に当てる習慣をつける。
