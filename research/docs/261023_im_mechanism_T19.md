# T19：Ibragimov–Müller を本番スペックで — 群馬の外れ値は地理の交絡だった

**作成日：2026年10月23日**

**標本：関東6県・2000–2023・4,584行・209市町村**

## 0. 要約

| 論点 | 結論 |
|---|---|
| **(a) $\delta_{2010}=0$ は IM で決定的に null** | 5通りすべてで有意でない。**本番スペックでは点推定の符号が反転する**（平均 -0.0005 〜 -0.0010、t = **-0.48 / -0.83**） |
| **群馬の外れ値は地理の交絡だった** | 群馬は**圧倒的に内陸**（`coast` = +1.74 SD、次点の栃木は +0.60）。`coast`・`forest` を統制すると $\delta_{p,2010}$ は **+0.01529 → -0.00560 と符号反転**し、他5県の平均からの乖離は **11.5 SD → 4.1 SD** に縮む |
| 都県間の散らばりも半減する | $\mathrm{sd}(\hat\delta_p)$ はプールで 0.00373 → **0.00167**、$\delta_{2010}$ で 0.00650 → **0.00280**。**T4 の年方向（0.0080 → 0.0034）と同じ挙動** |
| 1県除外の頑健性 | t は -0.85 〜 +0.71、p は 0.44 〜 0.83。**どの1県も結論を作っていない**（神奈川を抜いても t = -0.85） |
| 年飽和を群内で回すのは無理 | スペック C は大半の都県で4〜7個、**神奈川では41個**の係数が共線で落ちる。**倹約版（スペック B）を採る** |
| 全標本との食い違い | 全標本の $\delta_{2010}$ = +0.00505（t = 2.35、市町村クラスター）に対し IM は平均 ≈ 0。**estimand が違う**（T12 §7.1）うえ、IM の仮定の方が弱い |

**核心**：**地理の統制は、$\delta$ の「時間方向の異質性」だけでなく「空間方向の異質性」も半分に縮める。** T12 以来の「群馬依存」は、群馬が最も内陸であることの反映だった。そして **(a) は IM の下で null であることが一段はっきりした** — 論文が $\delta_{2010}$ に依存しない構成であることが、ここでも効いている。

---

## 1. 設計：本番スペックをそのまま群内で回すことはできない

IM は都県ごとに独立に推定した $G=6$ 個の値に t 検定を当てる。仮定は「都県内は任意の従属、都県間は独立、群内で漸近正規」で、Conley より弱い。

しかし本番スペック（T18）は年飽和の交差項が4系統（$h$・$D$・$G$・$F$）＋年×水準項が $3\times23=69$ 本ある。**神奈川は8市町村・177行しかない。** T12 §4.1 で既に起きていた共線の問題が、ここで決定的に悪化する。

したがって群内の式を推定可能な範囲まで落とし、**劣化の度合いを並べて示す**。

| | 群内の式 | パラメータ数 |
|---|---|---|
| **A0** | $h + D$ ＋ CTRL（**地理なし＝T12 と同じ**） | 3 |
| **A** | $h + D + G + F$ ＋ CTRL（本番コントロール、年飽和なし） | 5 |
| **B0** | A0 ＋ $\mathbb{1}[2010]\times(h, D)$（地理なし） | 5 |
| **B** | A ＋ $\mathbb{1}[2010]\times(h, D, G, F)$（**本番コントロール・倹約版**） | 9 |
| **C** | 年飽和（**本番と同じ**） | 96＋ |

$\delta_{2010}$ は B では $\hat\delta + \hat\delta_{\mathbb{1}[2010]}$、C では年別係数そのもの。

### 1.1 共線で落ちた係数の数

| 都県 | 市町村 | A0 | A | B0 | B | **C** |
|---|---|---|---|---|---|---|
| 茨城 | 44 | 0 | 0 | 0 | 0 | 6 |
| 栃木 | 30 | 0 | 0 | 0 | 0 | 4 |
| 群馬 | 28 | 0 | 0 | 0 | 0 | 7 |
| 埼玉 | 50 | 0 | 0 | 0 | 0 | 5 |
| 千葉 | 49 | 0 | 0 | 0 | 0 | 5 |
| **神奈川** | **8** | 0 | 0 | 0 | 0 | **41** |

**スペック B までは1つも落ちない。C は神奈川で41個が落ちるので信用できない。** 以降 **B を主、C を参考**として扱う。

## 2. 都県の地理的な位置づけ

標準化後の都県平均。`coast` が大きいほど内陸。

|---|---|---|---|---|
| 茨城 | 44 | -0.53 | -0.12 | 0.530 |
| 栃木 | 30 | +0.60 | +0.20 | 0.350 |
| **群馬** | 28 | **+1.74** | +0.22 | 0.262 |
| 埼玉 | 50 | +0.24 | -0.34 | 0.404 |
| 千葉 | 49 | -0.96 | +0.22 | 0.290 |
| 神奈川 | 8 | -1.05 | -0.09 | 0.343 |

**群馬は圧倒的に内陸である**（+1.74 SD。次点の栃木 +0.60 の約3倍）。T4 §2.6 で「海から遠いほど HD35 1日あたりの被害が大きい」と分かっているので、**地理を統制しない式では群馬の高温被害が `consol30` の交差項に押し込まれる**という機序が事前に予想できる。

### 3.3 群馬の外れ値は地理の交絡だった

| | 地理なし | **本番** | 他5県の平均からの乖離 |
|---|---|---|---|
| プール $\delta_p$ | **+0.00765** | **-0.00216** | 3.6 SD → **1.5 SD** |
| $\delta_{p,2010}$ | **+0.01529** | **-0.00560** | **11.5 SD → 4.1 SD** |

**どちらも符号が反転し、外れ値としての度合いが大きく縮む。**

これは次の一連の既存結果をまとめて説明する。

| 文書 | 既存の記述 | T19 の説明 |
|---|---|---|
| `panel_extension` §4.2 | 群馬除外で $\delta$ が +0.00140 → +0.00032（t 0.48）に落ちる | 群馬が最も内陸で、地理勾配が `consol30` 交差項に押し込まれていた |
| `261012_vcov_inference_T12.md` §4 | $\delta_{2010}$ は茨城 -0.0028 〜 **群馬 +0.0153** で符号が割れる | 同上。地理を入れると群馬は -0.0056 になる |
| T12 §7.2 | 「群馬を抜くと消える」は寄与の大きさではない（寄与 6.9%） | 寄与でもなく重みでもなく、**統制されていない地理勾配**だった |

### 3.4 都県間の散らばりも半減する — 年方向と同じ挙動

| 方向 | 地理なし | 本番 | 変化 |
|---|---|---|---|
| **年**（T4 §2.3、$\mathrm{sd}(\hat\delta_t)$） | 0.00799 | 0.00341 | **-57%** |
| **都県・プール**（$\mathrm{sd}(\hat\delta_p)$） | 0.00373 | 0.00167 | **-55%** |
| **都県・$\delta_{2010}$** | 0.00650 | 0.00280 | **-57%** |

**3つとも同じだけ縮む。** T4 §2.4 の結論（「$\delta_t$ の年次異質性の大半は年固有の空間的な熱感応度勾配」）は、**空間方向にもそのまま当てはまる**。

> **$\delta$ の見かけの異質性は、時間方向でも空間方向でも、同じ一つの原因 — 統制されていない地理勾配を `consol30` が代理していたこと — に帰着する。**

## 4. 全標本の推定値との食い違いをどう読むか

| | $\delta_{2010}$ | t |
|---|---|---|
| 全標本・市町村クラスター（T18） | **+0.00505** | **+2.35** |
| 全標本・Conley 50km（T18） | +0.00505 | +2.32 |
| **IM（本番・倹約版 B）** | **-0.00054**（6県平均） | **-0.48** |

**矛盾ではなく estimand が違う**（T12 §7.1 と同じ構図）。

- **全標本**：年FE も地理の傾き（$\gamma_t$・$\eta_t$）も**全県共通**に推定したうえでの $\delta_{2010}$
- **IM**：各県が**自分の年FE も自分の地理の傾きも**持つ

IM は群間独立を要求するので後者が正しい使い方である。そして**IM の仮定（都県内は任意の従属）は Conley の距離減衰より弱い**。

> **したがって (a) については IM の結論を採る。T12 §3.7 で決めた方針のとおりである。**

T18 §3.5 で「$\delta_{2010}$ の含意（高整備率では2010年の被害が完全に相殺）は農学的に強すぎる」と書いた警告とも整合する。**全標本の +0.00505 は上振れである。**

## 5. 論文への含意

1. **(a) は informative null として確定した。** T12（t = 0.69）→ T15（t = 0.98）→ T18（t = 2.35、ただし全標本）→ **T19（IM で t = -0.48、符号反転）**。論文が $\delta_{2010}$ の有意性に依存しない構成であることが、ここでも効いた
2. **「群馬依存」という長年の論点が解決した。** `panel_extension` §4.2 以来の記述を「地理勾配の交絡」として書き換える
3. **地理勾配の押し込みが、時間方向と空間方向で同じだけ起きている**（散らばりが3つとも 55〜57% 縮む）。これは T4 の主張を一段強める
4. **本番スペックの妥当性が補強された。** 地理を入れることで、年方向・空間方向の両方で見かけの異質性が減る
