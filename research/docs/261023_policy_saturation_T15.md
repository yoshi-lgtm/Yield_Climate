### 1.4 符号の想定は誤っていた

`261023_estimand_window_policy.md` §3.2 で「良田への集約 → 10a収量上昇 → $\delta_{2010}$ と同符号」と書いたが、**原典を読むと符号は決まらない**。少なくとも3つのチャネルが逆向きに働く。

| チャネル | 向き |
|---|---|
| (a) 過剰作付の解消 → 劣等地から降りる | 10a収量 **上昇**（上限は全国で面積の 3.1%） |
| (b) 交付が**作付面積**ベースなので、目標未達の農家は目標まで作付を**増やす** | 限界地が主食用米に入り 10a収量 **低下** |
| (c) 転作交付金が生産調整と切り離され、かつ手厚い（大豆 3.5万・新規需要米 8.0万円/10a）。**乾田地帯は大豆、湿田地帯は飼料用・米粉用米**（スライド5） | 乾田＝条件の良い田が主食用米から抜けると 10a収量 **低下** |

**符号が決まらないことは、対処の選択をむしろ正当化する。** バイアスの向きを議論で詰められない以上、水準項を**吸収する**しかない。これが T15 を頑健性ではなく本体に置く理由である。

## 2. 推定式

$$\ln y_{it} = \alpha_i + \tau_t + \underbrace{\sum_{t\neq 2000} \mathbb{1}[t]\cdot c_i}_{\textbf{追加（23本）}} + \sum_t \mathbb{1}[t]\cdot\big(\beta_t\,heat_{it} + \delta_t\,heat_{it} c_i\big) + \gamma X_{it} + \varepsilon_{it}$$

$c_i$ = `consol30` は時間不変なので $\sum_t \mathbb{1}[t]c_i = c_i$ が市町村FEと共線になる。基準年 2000 を落として 23 本とした。

$\omega_t$ も**作り直している**。$\tilde D$ は $D$ を他の**全**回帰子に射影した残差なので、飽和版では年 × `consol30` も射影対象に入る。

$$\omega_t=\frac{\sum_i \tilde D_{it}\, D_{it}}{\sum_{s}\sum_i \tilde D_{is}^2},\qquad \tilde D = M_{[\text{FE},\,heat,\,\mathbb{1}[t]c,\,X]}\,D$$

## 6. ではなぜ $\delta_{2010}$ が落ちるのか

**政策チャネルが検出されないのに $\delta_{2010}$ が 39% 落ちるのは矛盾ではない。** 2010年内で $heat\cdot c$ と $c$ が強く共線だからである（`261023_estimand_window_policy.md` §3.2 の代数：2010年はほぼ全市町村で $heat>0$、平均 9.67 なので $\mathrm{cov}_i(heat\cdot c,\ c)>0$）。

したがって飽和式では

> **「整備が2010年の高温害を緩和した」と「整備済み市町村の2010年の収量水準が高かった」を、データが区別できない。**

水準シフト +0.031（t 1.56）と $\delta_{2010}$ +0.00218（t 0.98）は、どちらも単独では有意でなく、合わせて baseline の $\delta_{2010}$ +0.00356（t 2.07）を構成していた。政策はその水準差の候補の**一つ**にすぎず、標高・経営規模・品種・その他の2010年固有の要因も同じ位置にある。

**これは T4 の horse race を本体に置く方針（`261004_goals_and_todo.md` T4）と同じ問題が、年固有ショックの形で現れたものである。** 単一事象設計では「複数事象で頑健」という逃げ道がない、という既存の認識がここでも効く。

## 8. 含意

| 帰無仮説 | baseline | saturated | 扱い |
|---|---|---|---|
| **(c) $\delta_t$ が全年同一**（論文の主題） | 棄却（98.4） | **棄却（81.9、p 1.5e-08）** | **飽和を本番スペックにする。主結果は無傷** |
| **(a) $\delta_{2010}=0$**（T4 の経済的主張） | t 2.07（クラスター）／0.69（IM） | **t 0.98（クラスター）／1.01（IM）** | **informative null。飽和後はどの VCV でも有意でない** |
| 政策チャネル（$\mathbb{1}[t]c_i$、2010–2012） | — | $\chi^2(3)$ = 3.96、p = 0.27 | **政策のステップは検出されない** |

### 8.1 論文への反映

1. **飽和スペックを本番にする。** $\delta_t$ は年固有の水準差ではなく**傾きの異質性のみ**から識別され、識別仮定の弱い版を課したことになる。2010年に何が起きたかを知らなくても、すべての年固有ショックの `consol30` 線形成分が落ちる
2. **(a) の扱いを一段強める。** T12 では「クラスターと Conley では境界的だが IM では有意でない」だったが、飽和後は**市町村クラスターでも t = 0.98** である。「頑健でない」ではなく「**飽和させると消える**」と書ける
3. **主結果の側は強まった。** 「年固有ショックを `consol30` に線形に効く範囲で全部吸収しても $\delta_t$ の異質性は $\chi^2(23)$ = 81.9 で棄却される」は、baseline の 98.4 より**反論しにくい**数字である
4. **汚染項の符号はスペック依存**と明記する。大きさ（報告値の約2割）は頑健だが向きは変わる（-18.5% → +24.2%）。T11・T12 の「-18.5%」を本文に書くときは水準・非飽和スペックの値であることを添える
5. **政策ショックは「対処済み」として脅威表に残す。** 検出されなかったこと自体より、**飽和で吸収する設計にしたこと**が主張である

### 8.2 残る作業

- **T17（2010年の作付面積反応）は依然として要る。** §1.4 のとおり面積チャネルの符号が決まらないので、$\Delta\ln(\text{作付面積})_{i,2010}$ を `consol30` に回帰して (a)(b)(c) のどれが効いたかを直接見る
